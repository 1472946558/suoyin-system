# 打印模块优先级

## 1. 判断原则

- 客户要求优先，不因“先能跑业务”就把打印完全后置。
- 但硬件型号未确定前，不做过深设备绑定。
- 第一阶段先把“打印结构”和“业务字段”定下来，再进入真机适配。

## 2. P0

### 2.1 小票打印

- 业务价值：
  - 收银完成后要有标准化输出
  - 方便客户现场核对与留档
- 技术复杂度：中
- 前置依赖：
  - 收银订单字段稳定
  - 门店、品牌、小票抬头配置
- 风险：
  - 打印机宽度未确认
  - 不同品牌驱动差异大
- 建议顺序：第一优先

### 2.2 标签打印基础结构

- 业务价值：
  - 客户已明确提到要再买一个打标签的设备
  - 后续商品/回收件标识需要
- 技术复杂度：中
- 前置依赖：
  - 标签尺寸口径
  - 标签字段口径
- 风险：
  - 设备型号未确认
  - 标签规格可能变化
- 建议顺序：第二优先

### 2.3 回收单打印留痕位

- 业务价值：
  - 回收业务是核心场景
  - 客户明确希望有照片时打印也能体现
- 技术复杂度：中高
- 前置依赖：
  - 回收单字段
  - 照片摘要方案
- 风险：
  - 直接打印照片对热敏小票兼容性差
  - 彩色打印要求可能推高适配复杂度
- 建议顺序：第三优先

## 3. P1

### 3.1 照片摘要打印

- 业务价值：
  - 比纯文字更符合客户直觉
- 技术复杂度：中
- 前置依赖：
  - 照片缩略图或“已留存”摘要字段
- 风险：
  - 不同打印机对图像支持差异大
- 建议：
  - 第一版可先做“照片已留存 + 数量 + 时间”
  - 第二版再尝试缩略图

### 3.2 彩色打印兼容

- 业务价值：
  - 客户偏好彩色小票
- 技术复杂度：高
- 前置依赖：
  - 彩色打印机型号
  - 驱动与接口协议
- 风险：
  - 很可能影响首版稳定性
- 建议顺序：在黑白热敏方案稳定后再进

### 3.3 多模板切换

- 业务价值：
  - 后续模板化卖给其他客户时很有用
- 技术复杂度：中
- 前置依赖：
  - 打印配置模型
- 风险：
  - 若过早做复杂模板编辑器，会拖慢首版

## 4. P2

### 4.1 可视化拖拽模板编辑

- 业务价值：高
- 技术复杂度：高
- 当前不建议进入第一期

### 4.2 多品牌打印驱动深度适配

- 业务价值：中
- 技术复杂度：高
- 当前不建议进入第一期

## 5. 建议实现顺序

1. 小票基础模板
2. 标签基础模板
3. 回收单留痕打印位
4. 照片摘要打印
5. 彩色打印适配
6. 多模板 / 可视化编辑

## 6. 当前结论

- 第一阶段不要把目标定成“支持所有打印机”。
- 应先把打印内容结构做稳，再等客户确定设备型号后做适配。
- 对回收业务来说，第一版最稳的方案不是直接打印大图，而是优先支持：
  - 回收单号
  - 客户信息
  - 金料信息
  - 金额
  - 照片数量
  - 照片已留存标记
