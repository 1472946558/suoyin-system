# 后台完整接管小程序数据源清单

更新时间：2026-06-07

## 目标

后台需要成为客户可直接使用的业务后台，覆盖小程序全部核心数据源，并支持可控的增删查改。

## 已完成

### 1. 后台可用模块

- 门店管理
  - 后台入口：`门店`
  - 能力：新增、编辑、停用
- 账号管理
  - 后台入口：`账号`
  - 能力：新增、编辑、停用、分配门店、分配角色
- 角色权限
  - 后台入口：`角色`
  - 能力：编辑角色名称、说明、数据范围、能力项
- 收银记录
  - 后台入口：`收银`
  - 能力：查看列表、查看订单详情、查看商品明细
- 回收录单
  - 后台入口：`回收`
  - 能力：查看列表、查看详情、查看照片留档入口
- 业务订单
  - 后台入口：`订单`
  - 能力：统一查看收银单和回收单
- 会员档案
  - 后台入口：`会员`
  - 能力：新增、编辑、停用
- 商品目录
  - 后台入口：`商品`
  - 能力：新增、编辑、停用
- 系统设置
  - 后台入口：`设置`
  - 能力：编辑品牌名、客服电话、小票标题、拍照规则、打印状态

- 商品补齐：`categoryTab`、`imageUrl`、`inventory`、`stockStatus`
- 收银单补齐：`customerName`、`customerPhone`、`itemSummary`、`items`
- 回收单补齐：`itemSummary`、`items`、`attachments`
- 会员已进入后台可编辑对象

## 小程序数据源到后台入口映射

### 门店

- 小程序数据用途：登录后门店范围、订单归属、商品归属、会员归属
- 后台入口：`门店`
- 当前能力：增、查、改、停用

### 账号

- 小程序数据用途：员工身份、门店范围、权限范围
- 后台入口：`账号`
- 当前能力：增、查、改、停用

### 角色权限

- 小程序数据用途：老板、店长、员工权限范围
- 后台入口：`角色`
- 当前能力：查、改

### 会员

- 小程序数据用途：会员列表、会员资料、回访备注
- 后台入口：`会员`
- 当前能力：增、查、改、停用

### 商品

- 小程序数据用途：商品目录、SKU、价格、库存显示
- 后台入口：`商品`
- 当前能力：增、查、改、停用

### 收银单

- 小程序数据用途：收银列表、订单详情、对账
- 后台入口：`收银`、`订单`
- 当前能力：查

### 回收单

- 小程序数据用途：回收录单、订单详情、确认金额、照片留档
- 后台入口：`回收`、`订单`
- 当前能力：查

### 回收照片

- 小程序数据用途：回收现场照片留档
- 后台入口：`回收` 详情
- 当前能力：查照片链接

### 系统设置

- 小程序数据用途：品牌名、客服电话、拍照规则、小票标题
- 后台入口：`设置`
- 当前能力：查、改

## 完成标准

- 客户登录后台后，每个模块都能点开
- 每个模块至少有列表或详情，不出现空白页
- 可编辑模块保存后，小程序读取到同一份最新数据
- 客户看不到开发交付口径文案
