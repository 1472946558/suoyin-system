# 线上后台验收报告

更新时间：2026-06-07

环境：

- 验收地址：`https://jinjiangguan.com/`
- 验收方式：真实浏览器登录后逐模块点击检查
- 验收目标：后台完整给客户使用，模块可打开，字段和文案面向客户，后台与小程序共用同一份业务数据

## 验收结论

结论：`不通过`

当前线上后台可以登录，且现有 7 个菜单都能打开并读到真实数据，但线上仍是旧的“简版后台”，不是本地已经补好的完整客户后台。

## 线上实际状态

### 当前线上菜单

- `首页`
- `收银`
- `录单`
- `订单`
- `会员`
- `商品`
- `设置`

### 当前线上通过项

- 后台可以登录
- 左侧现有 7 个菜单都能点开
- 页面没有出现空白页或白屏
- 数据来源是真实接口，不是纯本地假数据
- 收银、回收、订单、商品都能看到真实业务记录

## 核心不通过项

### P0. 线上仍是旧简版后台

- 页面标题仍为 `金匠倌简版后台`
- 首页仍出现“只保留日常业务入口”“小程序同口径简版”这类简版口径
- 当前线上缺少 `门店`、`账号`、`角色` 三个客户后台必备模块

影响：

- 客户无法在后台直接管理门店、账号、角色与权限
- 当前线上后台无法承担“小程序全部数据源由后台接管”的目标

### P0. 线上不是完整 CRUD 后台

- `会员` 页面当前只是说明型页面，不是会员列表和可编辑管理页
- `商品` 页面当前只有简版展示，不是完整新增/编辑/停用后台
- `设置` 页面当前主要是信息展示，不是完整客户可操作配置台
- `收银`、`录单`、`订单` 当前主要是查看，不是完整后台管理流

影响：

- 客户可读，但不可管
- 无法完成“后台修改后，小程序实时同步”的正式验收

### P0. 开发/联调/验收口径仍然暴露给客户

线上实际可见文案包括：

- `GOLD CASHIER ADMIN`
- `Simple Console`
- `Miniapp Front Desk`
- `后台已切换为小程序同口径简版`
- `V1最终验收测试客户-可删除`
- `integration smoke cashier`
- `上传联调客户`
- `OSS验收客户`
- `待确定小票机 / 标签机型号，客户倾向彩色小票`

影响：

- 客户会直接看到开发过程痕迹
- 当前线上不适合作为正式客户后台交付

### P0. 登录页仍暴露后台账号密码输入结果

- 登录页当前存在预填账号和密码

影响：

- 客户环境存在明显安全和交付风险

## 上线后二轮验收清单

### 1. 模块入口验收

- `门店` 是否出现并可打开
- `账号` 是否出现并可打开
- `角色` 是否出现并可打开
- `收银` 是否能进入详情
- `回收` 是否能进入详情并看到照片
- `订单` 是否能区分收银单与回收单
- `会员` 是否为真实列表页
- `商品` 是否为真实列表页
- `设置` 是否为真实可编辑页

### 2. 字段完整性验收

- 商品是否包含 `categoryTab`、`imageUrl`、`inventory`、`stockStatus`
- 收银单是否包含 `customerName`、`customerPhone`、`itemSummary`、`items`
- 回收单是否包含 `itemSummary`、`items`、`attachments`
- 回收详情是否能看到照片或照片入口

### 3. CRUD 验收

- 新增一个门店后，账号分配门店可立即选到
- 新增一个账号后，角色和门店范围保存成功
- 修改角色权限后，账号默认可见能力同步变化
- 新增会员后，小程序建单可带入
- 修改商品后，小程序商品目录同步更新
- 停用商品或会员后，小程序侧不再按正常可用对象展示

### 4. 文案验收

- 页面不再出现 `Simple Console`
- 页面不再出现 `Miniapp Front Desk`
- 页面不再出现“简版后台”导向文案
- 页面不再出现联调、验收、测试客户字样
- 页面不再出现内部待定事项文案

## 通过标准

- 客户登录后台后，看到的是完整客户后台，不是简版展示台
- 每个业务模块都能点开，且不是说明页
- 可编辑模块具备真实保存能力
- 后台修改后，小程序读取的是同一份最新数据
- 客户界面不再出现开发、联调、验收过程文案
