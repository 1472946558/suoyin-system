# 蓝牙打印现场验收清单

日期：2026-06-10

适用版本：小程序体验版 `0.2.1` 及之后，描述包含 `蓝牙打印接入与打印预览优化`。

## 验收目标

确认 NIIMBOT K3/K3_W 能在真实手机微信环境中完成小票和标签打印，且内容、中文、尺寸和二维码位置满足门店使用。

## 准备项

- 使用已上传体验版的小程序，不使用开发者工具模拟器代替真机。
- 手机开启蓝牙，并允许微信使用蓝牙权限。
- 打印机开机、装纸正常、电量充足，并处于可发现或可连接状态。
- 准备一张正式收银单和一张正式回收单，优先用线上真实接口生成的数据。

## 小票验收

1. 进入收银单详情页，点击 `打印小票`。
2. 确认预览区显示 `ESC/POS 小票指令`。
3. 点击发送打印，选择 NIIMBOT K3/K3_W 设备。
4. 确认小票能正常出纸。
5. 确认中文不乱码，至少包含标题、单号、类型、门店、操作员、客户、商品明细或回收明细、金额。
6. 确认标题优先使用后台设置的小票标题或品牌名，不应出现无关测试文案。

## 标签验收

1. 进入同一单据详情页，点击 `打印标签`。
2. 确认预览区显示 `TSC 标签指令`。
3. 点击发送打印，选择 NIIMBOT K3/K3_W 设备。
4. 确认标签能正常出纸，且没有连续空走纸。
5. 确认标签内容包含品牌、单号、门店、品名或摘要、成色或客户信息、净重或数量、金额。
6. 确认二维码完整、没有压到文字，扫码结果为当前单号。

## 异常处理

- 找不到设备：确认打印机已开机、手机蓝牙已开、微信蓝牙权限已打开，再点 `清除打印机` 后重试。
- 中文乱码：记录打印机型号、自检页代码页信息和出错照片，优先检查 GB18030/中文字体支持。
- 标签偏移：拍摄完整标签照片，记录纸张尺寸、间隙、打印方向和偏移量。
- 二维码被裁切：拍摄标签照片并记录单号长度，用于调整二维码坐标或尺寸。

## 通过标准

- 收银单小票可打印。
- 回收单小票可打印。
- 收银单标签可打印。
- 回收单标签可打印。
- 中文正常，金额和单号可核对。
- 标签二维码可扫码，且不会遮挡主要字段。
