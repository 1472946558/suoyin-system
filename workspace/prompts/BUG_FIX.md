# Prompt 模板：Bug 修复

## 使用场景
发现 Bug 需要修复时，用此模板生成调试 Prompt。

## 模板

```
## Bug 描述
[现象描述，用户能看到什么]

## 复现步骤
1. [步骤1]
2. [步骤2]
3. [步骤3]

## 错误输出
```
[粘贴完整的错误日志/堆栈信息]
```

## 疑似文件
[文件路径]:[行号]

## 期望行为
[修复后应该怎样]

## 约束
- 只修改 [指定范围]
- 不重构
- 保持向后兼容
- 最小改动

## 调试原则
1. 不猜，用日志和数据说话
2. 每次只改一个变量
3. 修复后必须跑验证
4. 记录 root cause
```

## 填写规则
1. **复现步骤**必须可稳定复现
2. **错误输出**必须完整粘贴
3. **疑似文件**给明确路径
4. **约束**必须包含"最小改动"
