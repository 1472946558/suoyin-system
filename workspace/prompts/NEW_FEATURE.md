# Prompt 模板：新功能开发

## 使用场景
需要开发一个新功能时，用此模板生成 Prompt 给 Cursor / Codex。

## 模板

```
## 上下文
项目：[项目名称]
技术栈：[语言/框架]
当前状态：[已有代码的简要描述]

## 任务
[一句话描述要做什么]

## 约束
- 只修改 [指定文件/目录]
- 不重构现有代码
- 不引入新依赖
- 保持向后兼容

## 要修改的文件
- [文件路径1]: [改动说明]
- [文件路径2]: [改动说明]

## 验收标准
- [ ] [具体可验证的标准1]
- [ ] [具体可验证的标准2]
- [ ] [具体可验证的标准3]

## 禁止事项
- 不要修改 [明确排除的文件]
- 不要添加 [明确排除的功能]
- 不要重构 [明确排除的代码]

## 输出要求
1. 修改文件清单
2. 最小 patch（只改必要的）
3. 日志关键字
4. 验收步骤
5. 风险边界
```

## 填写规则
1. **上下文**必须包含技术栈和当前状态
2. **约束**至少 3 条
3. **验收标准**可 yes/no 判断
4. **禁止事项**明确列出
5. 不确定的标注 `[待确认]`
