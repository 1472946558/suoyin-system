# 02 - 范围边界文档

## 1. V1 做什么

| 模块 | 功能 | 说明 |
|------|------|------|
| 顾客首页 | 轮播图 + 品牌文案 + 核心入口 + 门店预约入口 | 轮播图可后台维护 |
| 商品展示 | 分类、列表、详情 | 只展示，不含价格计算逻辑 |
| 黄金回收 | 服务介绍页 | 静态文案 + 流程说明 |
| 门店 | 列表、详情、最近推荐 | 经纬度后台填写，距离前端计算 |
| 到店预约 | 创建、查看、取消 | 需微信登录 + 手机号授权 |
| 我的预约 | 列表、详情 | 仅本人可见 |
| 我的页面 | 顾客信息 + 店长入口 | 店长入口在页面底部 |
| 店长入口 | 账号密码登录 | 按角色进入工作台 |
| 后台门店管理 | 增加经纬度编辑 | 现有管理后台扩展 |
| 后台预约管理 | 查看和操作预约 | 员工端预约管理 |

## 2. V1 不做什么

| 排除项 | 原因 |
|--------|------|
| 购物车 | V1 商品只展示 |
| 在线下单购买 | V1 不做交易 |
| 微信支付 | V1 不做交易 |
| 物流发货 | V1 不做交易 |
| 退款售后 | V1 不做交易 |
| 优惠券 | 二期 |
| 会员积分 | 二期 |
| 在线估价 | V1 回收只做介绍 |
| 在线回收结算 | V1 回收只预约到店 |
| 上门回收 | V1 不做 |
| 邮寄回收 | V1 不做 |
| 参考金价展示 | 顾客端不展示 |
| 顾客端订单管理 | V1 顾客只有预约，没有商品订单 |

## 3. 容易被客户误解的边界

1. **商品展示 ≠ 商品销售**：V1 展示商品信息和图片，但不支持在线购买。顾客看到喜欢的商品需要到店咨询。
2. **回收介绍 ≠ 在线回收**：V1 介绍回收服务流程，但不提供在线估价或在线结算。回收价格以门店线下检测为准。
3. **预约 ≠ 订单**：预约是到店服务预约，不是商品订单。预约不涉及支付。
4. **门店确认**：预约提交后需要门店员工确认才生效，不是提交即确认。
5. **位置不上传**：顾客位置仅在小程序内存中计算距离，不上传服务器，不落库。
6. **经纬度手动填写**：门店经纬度由管理员在后台手动填写，不自动解析地址。
7. **店长入口不显眼**：店长入口在"我的"页面底部，不影响顾客正常使用。
