# 03 - 页面交互规格文档

> 本文档详细描述 8 个顾客端原型页面的交互细节，作为前端开发的交互规范。
>
> 术语约定：管理端入口统一称"店长入口"。

---

## 一、全局交互规则

### 1.1 TabBar 交互

- TabBar 固定在底部，4 个 Tab：首页 / 款式 / 门店 / 我的。
- 选中色：#866E23（金色），未选中色：#8A8F99。
- 切换 Tab 使用 `wx.switchTab`，不保留 navigateTo 栈。
- Tab 切换时触发对应页面的 `onShow`，需重新拉取数据。

### 1.2 页面跳转方式

| 场景 | 跳转方式 | 说明 |
|------|----------|------|
| Tab 页之间切换 | `wx.switchTab` | 清空 navigateTo 栈 |
| 主包 → 分包页面 | `wx.navigateTo` | 保留返回栈 |
| 分包页面之间 | `wx.navigateTo` | 保留返回栈 |
| 预约提交成功 → 详情页 | `wx.redirectTo` | 不保留提交页（不能返回到已提交的表单） |
| 店长入口 → 员工端 | `wx.reLaunch`（N08 对接） | 清空所有页面栈 |

### 1.3 通用 Loading 规则

- 首次进入页面：全屏 loading 或骨架屏。
- 下拉刷新：显示系统下拉刷新动画，完成后 `wx.stopPullDownRefresh()`。
- 加载更多：列表底部 loading 指示器。
- 按钮提交：按钮禁用 + loading 文案（如"提交中..."）。

### 1.4 通用错误处理

| 错误类型 | 表现 |
|----------|------|
| 网络超时/断网 | toast "网络异常，请稍后重试" |
| 接口 500 | toast "服务器开小差了" |
| 接口 401（顾客） | 清除本地 token，显示未登录状态 |
| 接口 403 | toast "无权限访问" |
| 接口 404 | toast "数据不存在" |
| 业务错误（code≠0） | toast 后端返回的 message |

### 1.5 授权弹窗规则

- 位置授权：首次进入门店列表时自动请求，拒绝后不反复弹窗。
- 手机号授权：仅在预约提交和我的页登录时通过 `<button open-type="getPhoneNumber">` 触发。
- 微信登录：`wx.login` 静默进行，不弹窗。

## 二、首页交互规格

### 2.1 Banner 轮播图

| 交互项 | 规格 |
|--------|------|
| 轮播组件 | `<swiper>` 组件，`autoplay` 自动播放 |
| 轮播间隔 | 4000ms |
| 动画时长 | 500ms |
| 循环 | circular=true |
| 指示点 | 显示指示点，颜色 #866E23 |
| 手动滑动 | 支持左右滑动 |
| 点击跳转 | 按 linkType 跳转：products→switchTab 款式，stores→switchTab 门店，recycle→navigateTo 回收介绍，appointment→navigateTo 预约创建 |
| 空数据 | 显示默认品牌占位图 |

### 2.2 品牌文案区

- 静态展示，不响应点击。
- 品牌名："金匠倌"，字号 48rpx，加粗。
- 标语 1："旧金换打新款"，字号 28rpx。
- 标语 2："包损耗"，字号 28rpx。
- 品牌文案区包含完整品牌信息：金匠馆、旧金换打新款、包损耗、黄金维修、到店回收、款式定制。
- **"旧金回收 / 到店回收"仅作为品牌文案出现，不做独立按钮。**

### 2.3 核心入口

- 3 个入口：款式图 / 工费 / 点击看。
- 点击任一入口均 `switchTab` 到款式列表页。
- 入口样式：卡片式，图标 + 文字，横向排列。

### 2.4 附近门店卡片

- `onShow` 时重新拉取门店列表。
- 取第一个门店作为附近门店展示。
- 卡片显示：门店名称、地址、距离文案。
- 点击卡片 → `navigateTo` 门店详情页（带 id）。
- 点击"到店预约" → `navigateTo` 预约创建页（带 storeId）。
- 点击"地图导航" → 有经纬度调 `wx.openLocation`，无经纬度先拉详情再判断。
- 无门店时不显示卡片。

### 2.5 定位交互

- 首页不主动请求定位，门店列表页负责定位。
- 首页门店距离为模拟值（0.8km），需在后续迭代中接入真实定位。
- 门店卡片导航按钮在无经纬度时先调 `getStoreDetail(id)` 获取经纬度。

## 三、款式列表页交互规格

### 3.1 分类标签栏

| 交互项 | 规格 |
|--------|------|
| 布局 | 横向滚动 `<scroll-view scroll-x>` |
| 标签来源 | 首次加载 products 接口返回的 categories，前端拼接"全部"在最前 |
| 选中样式 | 文字 #866E23，底部 4rpx 下划线 |
| 未选中样式 | 文字 #8A8F99 |
| 切换行为 | 立即重新加载列表（page=1，按分类筛选） |
| 防抖 | 无需防抖（点击即触发，不等动画） |

### 3.2 搜索交互

| 交互项 | 规格 |
|--------|------|
| 搜索框 | `<input>` + 确认按钮 |
| placeholder | "搜索款式" |
| 触发搜索 | `bindconfirm`（键盘确认）或点击搜索按钮 |
| 清除按钮 | 有 keyword 时显示 ×，点击清空并重新加载 |
| 实时搜索 | 不支持（仅确认时触发） |
| 搜索参数 | keyword 传给 products 接口 |

### 3.3 商品列表交互

| 交互项 | 规格 |
|--------|------|
| 布局 | 双列网格，卡片间距 16rpx |
| 卡片内容 | 图片（正方形）+ 名称 + 品类 + 成色 + 价格 + 克重 |
| 图片加载 | `<image mode="aspectFill"`，相对路径用 absUrl() 补全 |
| 价格格式 | 有 retailPrice：`¥` + 千分位金额；无：`面议` |
| 克重格式 | 有 gramWeight：`Xg`；无：不显示 |
| 点击卡片 | `navigateTo` 款式详情页（带 id） |
| 触底加载 | `onReachBottom`，hasMore=true 且 loading=false 时触发 |
| 每页条数 | 20 条 |
| 加载更多指示 | 底部显示"加载中..."或"没有更多了" |

### 3.4 下拉刷新

- `onPullDownRefresh` 触发，重新加载列表（page=1）。
- 完成后调 `wx.stopPullDownRefresh()`。

### 3.5 空数据和错误

| 场景 | 表现 |
|------|------|
| 无商品 | 列表区域居中显示"暂无商品" |
| 接口失败 | 列表区域显示错误文案 + "重试"按钮，点击重新加载 |
| 加载中 | 首次加载显示全屏 loading；加载更多显示底部 loading |

## 四、款式详情页交互规格

### 4.1 商品图片

- 正方形展示，宽度 100%，`mode="aspectFill"`。
- 相对路径用 `absUrl()` 补全为绝对 URL。

### 4.2 款式说明组装

- 从商品字段组装 description：
  1. purity（成色）→ "足金999材质"
  2. recommendedScene（推荐场景）→ 原文
  3. tags（标签）→ 排除"新建"/"导入"/"待完善"后的标签，用"、"连接
- 三部分用"，"连接，末尾追加"，工艺精湛，款式典雅，适合日常佩戴及送礼，支持旧金换新与定制参考。"
- 所有字段为空时使用默认文案。

### 4.3 最近门店计算

| 交互项 | 规格 |
|--------|------|
| 数据来源 | 并发请求 `getProductDetail(id)` 和 `getStores()` |
| 定位可用 | 按距离排序取最近门店 |
| 无定位 | 取第一个有联系方式的门店 |
| 门店展示 | 门店名称 + 距离文案（无定位时为"附近"） |
| 点击门店 | `navigateTo` 门店详情页 |

### 4.4 底部操作栏

| 按钮 | 行为 |
|------|------|
| 到店预约 | `navigateTo` 预约创建页（带 nearestStore.id） |
| 咨询门店 | `switchTab` 门店列表页 |
| 客服电话 | `wx.makePhoneCall(servicePhone)`，无电话 toast |

## 五、门店列表页交互规格

### 5.1 定位交互

| 交互项 | 规格 |
|--------|------|
| 触发时机 | `onShow` 时调 `tryLocate()` |
| 定位方法 | `wx.getLocation({ type: 'gcj02' })` |
| 已有定位 | `app.globalData.userLocation` 存在时不再重复请求 |
| 定位成功 | 存入 `app.globalData.userLocation`，触发 `applyLocation()` 计算距离 |
| 定位失败 | 设置 `locError: '定位服务未开启，无法获取附近门店'` |
| 重新定位 | 点击"重新定位"按钮 → 删除 `userLocation` → 重新 `wx.getLocation` |
| 去设置 | 点击"去设置"按钮 → `wx.openSetting` → 成功后重新定位 |
| 拒绝定位后 | 仍可手动浏览和搜索门店，不强制要求定位 |

### 5.2 门店列表加载

| 交互项 | 规格 |
|--------|------|
| 列表接口 | `getStores()` → 不含经纬度 |
| 补齐经纬度 | 并发请求每个门店的 `getStoreDetail(id)` 补齐 longitude/latitude |
| 距离计算 | 有定位且有坐标时用 Haversine 公式计算 distance |
| 排序 | 有定位时按 distance 升序（无坐标排最后）；无定位时按原始顺序 |
| 营业状态 | 解析 businessHours 判断当前是否营业中（isOpen） |
| 关键词过滤 | 按 name/address/city 模糊匹配，实时过滤 |

### 5.3 门店卡片交互

| 交互项 | 规格 |
|--------|------|
| 点击卡片 | `navigateTo` 门店详情页（带 id） |
| 点击"电话" | `wx.makePhoneCall(contactPhone)`，无电话 toast "暂无联系电话" |
| 点击"预约" | `navigateTo` 预约创建页（带 storeId） |
| 点击"导航" | 有坐标 `wx.openLocation`；无坐标 toast "该门店暂未配置坐标" |
| 距离文案 | <1km 显示 m（如 800m）；≥1km 显示 km（如 1.2km）；无坐标为空 |

### 5.4 下拉刷新

- 并发执行 `loadStores()` 和 `tryLocate()`。
- 完成后调 `wx.stopPullDownRefresh()`。

## 六、到店预约页交互规格

### 6.1 门店信息交互

| 交互项 | 规格 |
|--------|------|
| 有 storeId | `onLoad` 时调 `getStoreDetail(storeId)` 加载门店信息 |
| 无 storeId | 提示"请选择门店"，点击门店区域 `switchTab` 门店列表 |
| 门店展示 | 门店名称 + 地址 + 联系电话 |
| 点击门店信息 | 有 storeId → `navigateTo` 门店详情页；无 → `switchTab` 门店列表 |
| 加载失败 | toast "门店加载失败" |

### 6.2 服务类型选择

| 交互项 | 规格 |
|--------|------|
| 服务类型 | 4 种：旧金换新(OLD_FOR_NEW)、黄金维修(REPAIR)、款式工费咨询(CONSULT)、到店回收咨询(RECYCLE) |
| 展示方式 | 2×2 网格，每项含图标 + 文字 |
| 选中样式 | 金色边框 + 浅金背景 |
| 未选中样式 | 灰色边框 + 白色背景 |
| 选择行为 | 点击即选中，不弹窗 |

### 6.3 日期选择交互

| 交互项 | 规格 |
|--------|------|
| 日期范围 | 未来 7 天（含今天） |
| 展示方式 | 横向滚动条，每项显示"今天/明天/周X" + "MM/DD" |
| 选中样式 | 金色背景 + 白色文字 |
| 切换行为 | 清空已选时段 → 重新加载 slots |
| 默认选中 | 今天 |

### 6.4 时段选择交互

| 交互项 | 规格 |
|--------|------|
| 时段来源 | `getStoreSlots(storeId, date)` |
| 时段范围 | 09:30-21:30，30 分钟粒度 |
| 展示方式 | 网格布局，每行 4 个 |
| 可选时段 | 正常颜色（金色边框），可点击 |
| 已过去（当天） | 置灰，不可点击 |
| 已约满 | 置灰 + "约满"标记，不可点击 |
| 已关闭 | 置灰 + "休息"标记，不可点击 |
| 选中样式 | 金色背景 + 白色文字 |
| 切换日期 | 清空已选时段，重新加载 |
| 无时段 | "该日暂无可选时段" |
| 加载中 | 时段区域 loading |
| 加载失败 | 时段列表清空，不报错 |

### 6.5 手机号授权交互

| 交互项 | 规格 |
|--------|------|
| 触发方式 | `<button open-type="getPhoneNumber" bindgetphonenumber="onGetPhone">` |
| 授权成功 | `e.detail.errMsg === 'getPhoneNumber:ok'` → 拿到 `e.detail.code` |
| 授权拒绝 | toast "需要手机号授权才能预约" |
| 未登录先登录 | 无 token 时先调 `ensureCustomerSession()` 静默登录 |
| 手机号回填 | `customerPhoneAuth(phoneCode)` 成功后回填 contactPhone |
| phoneVerified | 授权成功后设为 true |
| 授权中 | `wx.showLoading({ title: '验证中...' })` |
| 授权失败 | toast 错误信息 |

### 6.6 提交预约交互

| 交互项 | 规格 |
|--------|------|
| 校验顺序 | 门店 → 服务类型 → 日期 → 时段 → 联系人姓名 → 手机号格式 → 手机号已授权 |
| 校验失败 | toast 对应提示 |
| 提交中 | 按钮禁用 + 文案"提交中..." |
| 提交成功 | toast "预约提交成功" → 1 秒后 `redirectTo` 预约详情页 |
| 重复预约 | 弹窗 "该时段已有有效预约，请选择其他时段" |
| 时段已满 | 弹窗 "该时段已约满，请选择其他时段" |
| 其他失败 | toast 错误信息 |
| 防重复提交 | submitting 标记，提交中不可再次点击 |

### 6.7 登录状态恢复

- `onShow` 时检查本地 token 和 profile，有则恢复登录状态。
- 已登录且已授权手机号时，contactName 和 contactPhone 自动回填。

## 七、我的预约页交互规格

### 7.1 状态筛选标签

| 交互项 | 规格 |
|--------|------|
| 标签列表 | 全部 / 待确认 / 已确认 / 已完成 / 已取消 |
| 展示方式 | 横向标签栏 |
| 选中样式 | 金色文字 + 底部下划线 |
| 切换行为 | 前端过滤 filteredList，不重新请求接口 |
| 默认选中 | "全部" |

### 7.2 预约卡片交互

| 交互项 | 规格 |
|--------|------|
| 排列顺序 | 按创建时间倒序 |
| 卡片内容 | 门店名称 + 服务类型文案 + 日期 + 时段 + 状态标签（带颜色） |
| 状态颜色 | 待确认=#FF9800，已确认=#4CAF50，已到店=#1976D2，已完成=#8A8F99，已取消=#B0B5BD，未到店/已终止=#F44336 |
| 点击卡片 | `navigateTo` 预约详情页（带 id） |

### 7.3 未登录处理

| 交互项 | 规格 |
|--------|------|
| 判断时机 | `onLoad` 时检查 `getCustomerToken()` |
| 未登录 | 不请求列表，显示"请先登录" + "去登录"按钮 |
| 去登录 | `navigateTo` 预约创建页（触发登录流程） |
| 401 错误 | 设置 `isLoggedIn: false`，显示未登录引导 |

### 7.4 刷新交互

| 交互项 | 规格 |
|--------|------|
| 下拉刷新 | `onPullDownRefresh` → 重新加载列表 |
| 返回刷新 | `onShow` 时如果已登录则重新加载（状态可能已变化） |
| FAB 新建 | 右下角悬浮按钮，点击 `navigateTo` 预约创建页 |

## 八、预约详情页交互规格

### 8.1 状态头部

| 交互项 | 规格 |
|--------|------|
| 背景 | statusColor 作为背景色 |
| 文字 | statusText 白色文字，居中 |
| 预约编号 | appointmentNo 灰色小字 |

### 8.2 取消预约交互

| 交互项 | 规格 |
|--------|------|
| 显示条件 | 状态为 PENDING 或 CONFIRMED，且距预约时间 >2 小时 |
| 不满足条件 | 不显示"取消预约"按钮 |
| 点击行为 | `wx.showModal` 二次确认 |
| 确认弹窗 | title: "取消预约"，content: "确定要取消此预约吗？取消后不可恢复。"，confirmColor: "#F44336" |
| 确认取消 | 调 `cancelAppointment(id, '用户取消')` |
| 取消成功 | toast "已取消" → 重新加载详情 |
| 取消失败 | toast 错误信息 |
| 时间计算 | `new Date(appointmentDate + 'T' + startTime + ':00')` 距当前 >2*60*60*1000 |

### 8.3 修改备注交互

| 交互项 | 规格 |
|--------|------|
| 显示条件 | 状态为 PENDING 或 CONFIRMED |
| 不满足条件 | 不显示"修改备注"按钮 |
| 点击行为 | `navigateTo` 预约备注页（带 id + encodeURIComponent(remark)） |
| 返回刷新 | `onShow` 重新加载详情（备注可能已修改） |

### 8.4 联系门店交互

| 交互项 | 规格 |
|--------|------|
| 拨打电话 | `wx.makePhoneCall(storePhone)`，无电话 toast "暂无门店电话" |
| 导航到店 | 有 storeLongitude/latitude → `wx.openLocation`；无 → toast "该门店暂未配置位置" |

### 8.5 信息展示

| 信息项 | 展示规则 |
|--------|----------|
| 门店名称 | storeName |
| 门店地址 | storeAddress |
| 服务类型 | serviceText（映射文案） |
| 预约日期 | appointmentDate |
| 预约时段 | startTime + '-' + endTime |
| 联系人 | contactName |
| 联系电话 | contactPhone |
| 备注 | remark，为空显示"无备注" |
| 创建时间 | createdAt |
| 确认时间 | confirmedAt，为空不显示 |
| 取消时间 | cancelledAt，为空不显示 |

## 九、我的页交互规格

### 9.1 顾客头部交互

| 状态 | 表现 |

| 交互项 | 规格 |
|--------|------|
| 触发方式 | `<button open-type="getPhoneNumber" bindgetphonenumber="onGetPhone">` |
| 授权成功 | `e.detail.code` → 无 token 先 `ensureCustomerSession()` → `customerPhoneAuth(code)` |
| 授权中 | `wx.showLoading({ title: '验证中...' })` |
| 授权成功后 | 更新 profile，toast "授权成功" |
| 授权失败 | toast 错误信息 |
| 授权拒绝 | 不处理（不报错） |

### 9.3 手机号脱敏

- 格式：前 3 位 + `****` + 后 4 位（如 138****1234）。
- 脱敏在展示层处理，不影响存储和传输。

### 9.6 退出登录交互

| 交互项 | 规格 |
|--------|------|

| 确认退出 | 调 `customerLogout()` → 清除本地 → 更新头部 |
| 退出成功 | toast "已退出" |
| 退出失败 | 清除本地 session，仍更新头部（兜底） |

### 9.7 客服电话交互

| 无电话 | toast "暂无客服电话" |

### 9.8 信息刷新

- `onShow` 时从本地存储读取 profile 并展示。
- 同时静默调 `getMe()` 刷新 profile。
- `getMe()` 成功后更新本地存储和页面。
- `getMe()` 失败时使用本地缓存的 profile，不报错。

## 十一、关键业务规则交互汇总

| 规则 | 交互表现 |
|------|----------|
| 顾客不用账号密码 | 我的页只有微信登录 + 手机号授权，无账号密码输入 |
| 游客可浏览 | 首页/款式/门店/回收介绍不要求登录 |
| 预约才授权 | 预约提交时才触发微信登录 + 手机号授权 |
| 店长入口 | 我的页底部，文案"店长入口"，副文案"门店店长 / 管理员登录" |
| 店长用账号密码 | N08 对接后 `reLaunch` 到员工端登录页 |
| 后端权限校验 | 顾客 token 不能调员工接口，员工 token 不能调顾客接口 |
| 门店经纬度后台填 | 顾客端只读，导航时用详情接口的经纬度 |
| 定位失败可手选 | 定位失败时门店列表仍可浏览和搜索 |
| 取消提前 2h | 距预约 ≤2h 不显示取消按钮 |
| 时段 30 分钟 | 09:30-21:30，30 分钟粒度 |
| 可预约 7 天 | 日期选择为未来 7 天（含今天） |
| 当天提前 1h | 已过去的时段置灰 |
| 同手机号同门店同时段不重复 | 重复预约弹窗提示 |
| 旧金回收不做首页独立按钮 | 仅作为品牌文案出现 |
