# 03 - 页面验收清单文档

> 本文档为 8 个顾客端原型页面 + 3 个辅助页面的验收检查清单，每个页面至少 5 条验收标准。
>
> 验收方式：微信开发者工具真机预览 + 后端 API 联调。
>
> 术语约定：管理端入口统一称"店长入口"。

---

## 验收通过标准

1. 所有 P0 验收项（权限隔离 8 项 + 异常场景 15 项 + 回归 10 项 = 33 项）必须 100% 通过。
2. 各页面验收项通过率 ≥ 90%。
3. 不存在 P0 级别的 bug（崩溃、数据泄露、权限绕过）。
4. 关键业务流程可走通：游客浏览 → 预约提交 → 我的预约查看 → 预约详情 → 取消预约。
5. 顾客与员工身份完全隔离，后端接口权限校验无遗漏。
