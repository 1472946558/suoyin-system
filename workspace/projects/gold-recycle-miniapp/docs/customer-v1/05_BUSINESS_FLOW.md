# 05 - 业务流程文档

## 1. 顾客浏览流程

```
用户打开小程序
  ↓
默认进入顾客首页
  ↓
┌─ 浏览轮播图 → 点击跳转对应页面
├─ 点击"款式图" → 商品列表
├─ 点击"工费" → 商品列表
├─ 点击"点击看" → 商品列表
├─ 点击"地图门店" → 门店列表
├─ 点击"附近门店" → 门店列表（按距离）
├─ 点击"到店预约" → 预约创建
└─ 点击"黄金回收" → 回收介绍

商品列表 → 点击商品 → 商品详情 → 点击"到店咨询" → 门店列表
门店列表 → 点击门店 → 门店详情 → 拨打电话 / 地图导航 / 预约到店
回收介绍 → 点击"到店预约" → 预约创建
```

**关键点**：以上全部流程游客可操作（浏览），无需登录。只有提交预约时需要授权。

## 2. 顾客预约流程

```
进入预约创建页
  ↓
选择门店（默认最近门店，可手动切换）
  ↓
选择日期（未来 7 天）
  ↓
选择时间（30 分钟粒度）
  ↓
填写联系人姓名
  ↓
联系人手机号
  ↓
检查是否已登录
  ├─ 未登录 → 微信登录（wx.login → code → 后端 jscode2session → 获取 openid）
  │    ↓
  │    创建/更新顾客档案
  │    ↓
  │    返回顾客 token
  └─ 已登录 → 继续
  ↓
检查是否已授权手机号
  ├─ 未授权 → 弹出手机号授权（getPhoneNumber → phoneCode → 后端换算手机号）
  │    ↓
  │    更新顾客档案手机号
  └─ 已授权 → 继续
  ↓
提交预约
  ↓
后端校验：
  ├─ 时间有效性（当天提前 1 小时，7 天范围内）
  ├─ 重复预约检查（同一手机号 + 同一门店 + 同一时间段）
  └─ 门店有效性
  ↓
创建预约（状态 PENDING）
  ↓
返回预约详情
```

## 3. 微信登录和手机号授权流程

### 3.1 微信登录

```
小程序前端                     后端                         微信服务器
    │                           │                              │
    │  wx.login() → code        │                              │
    │──────────────────────────→│                              │
    │                           │  jscode2session(code)        │
    │                           │─────────────────────────────→│
    │                           │  ←─ openid, session_key      │
    │                           │                              │
    │                           │  findOrCreateCustomerByOpenID│
    │                           │  创建/更新顾客档案            │
    │                           │                              │
    │                           │  createCustomerSession       │
    │                           │  生成顾客 token              │
    │                           │  存入 Redis（customer_session:前缀）│
    │                           │                              │
    │  ←── token + profile      │                              │
    │                           │                              │
```

### 3.2 手机号授权

```
小程序前端                     后端                         微信服务器
    │                           │                              │
    │  <button open-type="getPhoneNumber">
    │  用户点击授权              │                              │
    │  → e.detail.code (phoneCode)                             │
    │──────────────────────────→│                              │
    │                           │  getWechatAccessToken        │
    │                           │─────────────────────────────→│
    │                           │  ←── access_token            │
    │                           │                              │
    │                           │  getuserphonenumber(phoneCode)│
    │                           │─────────────────────────────→│
    │                           │  ←── phone_info              │
    │                           │                              │
    │                           │  updateCustomerPhone         │
    │                           │  更新顾客档案手机号           │
    │                           │                              │
    │  ←── success              │                              │
    │                           │                              │
```

## 4. 店长登录流程

```
我的页面 → 点击"店长入口"
  ↓
店长登录页
  ↓
输入用户名/手机号 + 密码
  ↓
后端校验
  ├─ 账号密码正确 → 创建员工 session（session: 前缀）
  │    ↓
  │    返回 token + 用户信息（含角色、权限）
  │    ↓
  │    根据角色跳转：
  │    ├─ store_staff → 门店工作台
  │    ├─ store_manager → 门店工作台（含管理功能）
  │    └─ super_admin → 管理端
  │
  └─ 账号密码错误 → 提示错误
```

**关键点**：
- 员工 token 和顾客 token 完全隔离
- 店长登录后不影响顾客身份（如果已有顾客 token，仍然保留）
- 店长退出登录不影响顾客身份

## 5. 员工处理预约流程

```
店长登录 → 进入预约管理页
  ↓
查看预约列表（按日期/状态筛选）
  ↓
点击预约 → 查看详情
  ↓
操作预约：
  ├─ 确认预约：PENDING → CONFIRMED（记录确认人、确认时间）
  ├─ 标记到店：PENDING/CONFIRMED → ARRIVED
  ├─ 完成预约：ARRIVED → COMPLETED（记录完成时间）
  ├─ 标记未到：PENDING/CONFIRMED → NO_SHOW
  └─ 终止预约：→ TERMINATED
  ↓
状态更新成功 → 刷新列表
```

**权限校验**：
- store_staff 只能操作本门店预约
- store_manager 只能操作本门店预约
- super_admin 可操作所有门店预约

## 6. 管理员维护门店经纬度流程

```
管理员登录后台
  ↓
进入门店管理
  ↓
选择门店 → 编辑
  ↓
填写/修改：
  ├─ 门店地址
  ├─ 经度（longitude）
  ├─ 纬度（latitude）
  ├─ 联系电话
  └─ 营业时间
  ↓
保存
  ↓
后端更新 StoreInfo（存入 app_configs JSON）
  ↓
顾客端门店列表/详情实时获取最新数据
```

**关键点**：
- 经纬度手动填写，不自动解析地址
- 顾客端门店列表不返回经纬度（安全考虑）
- 顾客端门店详情返回经纬度（用于地图导航）

## 7. 预约状态流转详细

```
                 ┌──────────────┐
                 │   PENDING    │ ← 顾客创建预约
                 │   待确认      │
                 └──┬───┬───┬───┘
                    │   │   │
          门店确认  │   │   │ 顾客取消（≥2h）
                    ▼   │   ▼
             ┌─────────┐│  ┌──────────┐
             │CONFIRMED││  │CANCELLED │
             │ 已确认   ││  │ 已取消    │
             └──┬──┬───┘│  └──────────┘
                │  │    │
      顾客到店  │  │    │ 标记未到
                ▼  │    ▼
          ┌────────┐│  ┌──────────┐
          │ARRIVED ││  │NO_SHOW   │
          │ 已到店  ││  │ 未到店    │
          └───┬────┘│  └──────────┘
              │     │
      完成回收 │     │ 终止
              ▼     ▼
         ┌─────────┐ ┌───────────┐
         │COMPLETED│ │TERMINATED │
         │ 已完成   │ │ 已终止     │
         └─────────┘ └───────────┘

特殊情况：PENDING 可直接 → ARRIVED（未确认直接到店）
```

### 状态转换规则

| 当前状态 | 可转换到 | 操作人 |
|----------|----------|--------|
| PENDING | CONFIRMED | 门店员工+ |
| PENDING | ARRIVED | 门店员工+ |
| PENDING | CANCELLED | 顾客（≥2h）/ 门店员工+ |
| PENDING | NO_SHOW | 门店员工+ |
| PENDING | TERMINATED | 门店员工+ |
| CONFIRMED | ARRIVED | 门店员工+ |
| CONFIRMED | CANCELLED | 顾客（≥2h）/ 门店员工+ |
| CONFIRMED | NO_SHOW | 门店员工+ |
| CONFIRMED | TERMINATED | 门店员工+ |
| ARRIVED | COMPLETED | 门店员工+ |
| ARRIVED | TERMINATED | 门店员工+ |
| COMPLETED | — | 终态 |
| CANCELLED | — | 终态 |
| NO_SHOW | — | 终态 |
| TERMINATED | — | 终态 |
