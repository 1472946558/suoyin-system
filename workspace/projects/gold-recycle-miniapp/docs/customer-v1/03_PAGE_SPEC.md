# 03 - 页面规格文档

## 1. 顾客端页面

### 1.1 首页（pkg-customer/pages/home/index）

**权限**：guest

**布局**：
- 顶部：轮播图 Banner（多张图片，可滑动，可后台维护）
- 中间：品牌文案区（金匠馆 / 旧金换打新款 / 包损耗）
- 核心入口：款式图 / 工费 / 点击看
- 底部：地图门店 / 附近门店 / 到店预约入口

**字段**：
- banners: 轮播图列表（imageUrl, linkType, linkUrl）
- brandName: "金匠馆"
- brandSlogan1: "旧金换打新款"
- brandSlogan2: "包损耗"
- servicePhone: 客服电话

**按钮**：
- 点击轮播图 → 跳转对应页面（商品/回收/预约/门店）
- 点击"款式图" → 商品列表
- 点击"工费" → 商品列表（按工费排序）
- 点击"点击看" → 商品列表
- 点击"地图门店" → 门店列表（带地图）
- 点击"附近门店" → 门店列表（按距离排序）
- 点击"到店预约" → 预约创建页

**异常**：
- 网络失败：显示默认品牌文案 + 重试按钮
- 轮播图为空：显示默认品牌图片

---

### 1.2 商品列表（pkg-customer/pages/products/list）

**权限**：guest

**字段**：
- 分类筛选标签栏（全部 + 各分类）
- 商品卡片：图片、名称、品类、成色、零售价、克重
- 分页加载（20 条/页）

**按钮**：
- 点击分类 → 筛选
- 点击商品卡片 → 商品详情

**异常**：
- 无商品：显示"暂无商品"
- 网络失败：显示重试按钮

---

### 1.3 商品详情（pkg-customer/pages/products/detail）

**权限**：guest

**字段**：
- 商品图片
- 名称、品类、成色
- 零售价、克重
- 推荐场景
- 标签

**按钮**：
- 返回列表
- 到店咨询（跳转门店列表）

**异常**：
- 商品不存在：显示"商品不存在" + 返回按钮

---

### 1.4 黄金回收介绍（pkg-customer/pages/recycle/info）

**权限**：guest

**字段**：
- 标题：黄金回收服务
- 内容：服务介绍文案
- 流程：1.到店咨询 2.黄金检测 3.确认价格 4.完成回收
- 备注：最终回收价格以门店线下检测为准

**按钮**：
- 到店预约 → 预约创建页

---

### 1.5 门店列表（pkg-customer/pages/stores/list）

**权限**：guest

**字段**：
- 门店卡片：名称、城市、地址、联系电话、营业时间、距离（km）
- 距离排序（如果获取到位置）

**按钮**：
- 拨打电话
- 查看详情
- 预约到店

**异常**：
- 拒绝位置授权：提示"未获取位置，无法按距离排序" + 手动选择
- 无门店：显示"暂无门店"

---

### 1.6 门店详情（pkg-customer/pages/stores/detail）

**权限**：guest

**字段**：
- 名称、城市、地址、联系电话、营业时间
- 经度、纬度（用于地图导航）

**按钮**：
- 拨打电话
- 地图导航（打开微信地图）
- 预约到店

---

### 1.7 到店预约（pkg-customer/pages/appointment/create）

**权限**：customer（需微信登录 + 手机号授权）

**字段**：
- 门店选择（默认最近门店，可手动切换）
- 日期选择（未来 7 天）
- 时间选择（30 分钟粒度）
- 联系人姓名
- 联系人手机号（从微信授权获取）
- 备注

**按钮**：
- 提交预约

**校验**：
- 当天预约至少提前 1 小时
- 同一手机号 + 同一门店 + 同一时间段不能重复
- 必须授权手机号

**异常**：
- 未登录：弹出微信登录授权
- 未授权手机号：弹出手机号授权
- 重复预约：提示"该时间段已有预约"
- 时间无效：提示"请选择有效时间"

---

### 1.8 我的预约（pkg-customer/pages/appointment/list）

**权限**：customer

**字段**：
- 预约卡片：门店名称、日期、时间、状态、状态文案
- 按创建时间倒序

**按钮**：
- 查看详情
- 取消预约（距预约时间 >= 2 小时）

**异常**：
- 未登录：弹出微信登录
- 无预约：显示"暂无预约"

---

### 1.9 预约详情（pkg-customer/pages/appointment/detail）

**权限**：customer

**字段**：
- 门店名称、地址、电话
- 预约日期、时间
- 状态、状态文案
- 备注
- 创建时间
- 确认时间（如有）
- 取消时间（如有）

**按钮**：
- 拨打电话
- 地图导航
- 取消预约（距预约时间 >= 2 小时且状态为 PENDING/CONFIRMED）

---

### 1.10 我的页面（pkg-customer/pages/mine/index）

**权限**：guest（未登录显示游客状态）

**字段**：
- 头像、昵称（已登录）/ "点击登录"（未登录）
- 手机号（脱敏，已登录）
- 我的预约入口
- 黄金回收介绍入口

**底部**：
- 员工入口按钮 → 跳转员工登录页

---

## 2. 员工入口

### 2.1 员工登录（pages/account/index）

**权限**：guest

**字段**：
- 用户名/手机号
- 密码

**按钮**：
- 登录

**登录成功后**：
- store_staff → 门店工作台
- store_manager → 门店工作台（含管理功能）
- super_admin → 管理端

---

### 2.2 员工预约管理（pages/appointments/index）

**权限**：store_staff+

**字段**：
- 预约列表：顾客姓名、手机号、门店、日期、时间、状态
- 按日期/状态筛选

**操作**：
- 确认预约（PENDING → CONFIRMED）
- 标记到店（PENDING/CONFIRMED → ARRIVED）
- 完成预约（ARRIVED → COMPLETED）
- 标记未到店（PENDING/CONFIRMED → NO_SHOW）
- 终止预约（→ TERMINATED）
