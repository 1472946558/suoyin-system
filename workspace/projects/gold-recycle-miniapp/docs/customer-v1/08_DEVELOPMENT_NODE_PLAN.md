## 节点详情

### N00 - 备份

- **目标**：在生产环境做任何改动前，先完整备份
- **内容**：源码、数据库、服务器配置、微信后台配置
- **验收**：有备份文件；能回滚；Git 分支干净
- **回滚**：无（这是第一步）

### N01 - 审计 ✅

- **目标**：审计原项目，明确复用和改造范围
- **输出**：审计报告（已完成）
- **验收**：明确哪些能复用、哪些必须改
- **结论**：可以继续开发

### N02 - PRD 冻结 ✅

- **目标**：冻结顾客端 PRD、页面范围、业务边界
- **输出**：PRD 文档、范围边界文档
- **验收**：客户确认边界
- **关键决策**：
  - 顾客身份：微信 openid + 手机号
  - 员工身份：账号密码 + 角色
  - 默认进入顾客端，员工入口在"我的"
  - 游客可浏览，预约时才授权

### N03 - 数据/权限设计 ✅

- **目标**：设计数据模型、权限模型、状态机
- **输出**：数据模型文档、权限矩阵、业务流程文档
- **验收**：明确顾客表、预约表、门店经纬度字段、角色权限
- **实现状态**：后端数据层已实现（customer_types.go, customer_store.go）

### N04 - 接口文档 ✅

- **目标**：输出接口文档
- **输出**：接口文档草案
- **验收**：全部接口有入参、出参、权限说明

### N05 - 页面流程验收用例 ✅

- **目标**：页面流程和验收用例
- **输出**：页面规格文档、验收用例文档
- **验收**：每个页面有入口、字段、按钮、异常状态、验收标准

### N06 - 后端开发 ✅

- **目标**：实现顾客登录、手机号授权、门店、商品、预约接口
- **依赖**：N04 接口文档
- **内容**：
  1. 实现顾客端 HTTP handler 函数
  2. 在 app.go Router() 中注册 `/api/v1/customer/*` 路由
  3. 实现顾客 token 中间件（与员工 token 隔离）
  4. 实现员工预约管理 handler + 路由
  5. 后台门店编辑增加经纬度字段支持
- **已就绪**：
  - customer_types.go（类型定义）✅
  - customer_store.go（数据访问层）✅
  - StoreInfo 经纬度字段 ✅
  - 微信登录流程 ✅
  - HTTP handler 函数 ✅
  - 路由注册 ✅
  - 顾客 token 中间件 ✅
  - 员工预约管理 handler ✅
  - 后台门店经纬度编辑 ✅
- **验收**：接口可跑通；顾客和员工权限隔离；预约能创建和查询
- **回滚**：删除新增 handler 和路由，不影响现有功能

### N07 - 顾客端开发 🔄（子阶段 1 ✅）

- **目标**：小程序顾客端页面开发
- **依赖**：N06 后端接口
- **项目组织**：miniapp-customer/ 独立小程序（与 miniapp/ 员工端分离），主包含 4 TabBar 页 + pkg-customer/ 分包含子页面
- **TabBar 方案**：原生 TabBar（4 Tab：首页/款式/门店/我的，金色 #866E23 选中色）
- **子阶段划分**：
  1. ✅ 子阶段 1：项目骨架 + 公共层（5 个 utils）+ TabBar 图标 + 首页（Tab 1）+ 其他 3 Tab 占位
  2. ⏳ 子阶段 2：款式 Tab（列表+详情）+ 门店 Tab（列表+详情）
  3. ⏳ 子阶段 3：预约模块（创建+列表+详情+修改备注）+ 我的 Tab（用户卡+快捷入口+服务卡片+员工入口）
- **子阶段 1 交付**：
  - 30+ 文件已创建（app.js/app.json/app.wxss、4 主包页、5 utils、8 TabBar PNG、README）
  - JS/JSON 语法全部校验通过
  - 端到端联调：首页可加载 home + stores 真实数据
  - HTML 预览版 `preview-home.html` 可在浏览器查看
- **待完成**：
  - 6 个 pkg-customer/ 子页面（product-detail/store-detail/appointment-create/appointments/appointment-detail/appointment-notes/recycle-info）
  - 自定义 TabBar 图标（当前是占位圆点）
  - 完善 3 个 Tab 占位页（products/stores/mine）
- **验收**：打开默认顾客端；可看商品、门店、提交预约、查看我的预约
- **回滚**：删除 miniapp-customer/ 整个项目，不影响 miniapp/ 员工端

### N08 - 员工端改造

- **目标**：员工从"我的-员工入口"登录
- **依赖**：N06 后端接口
- **验收**：员工从"我的-员工入口"登录；按角色进入对应页面
- **回滚**：恢复原登录入口

### N09 - 管理后台改造

- **目标**：后台可维护商品、门店、经纬度、预约记录
- **依赖**：N06 后端接口
- **验收**：可维护商品、门店、经纬度、预约记录
- **回滚**：恢复原后台页面

### N10 - 联调测试

- **目标**：联调测试、安全修复
- **依赖**：N07, N08, N09
- **验收**：顾客不能访问员工接口；员工不能越权；关键流程真机跑通
- **回滚**：无（测试阶段）

### N11 - 微信隐私提审

- **目标**：微信隐私协议、位置权限、代码提审
- **依赖**：N10
- **验收**：微信开发者工具无隐私报错；提审资料完整
- **回滚**：无（提审阶段）

### N12 - 上线部署

- **目标**：上线部署和交付
- **依赖**：N11
- **验收**：生产环境可访问；客户验收通过；交付账号、源码、数据库说明
