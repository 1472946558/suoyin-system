## 节点详情

### N00 - 备份

- **目标**：在生产环境做任何改动前，先完整备份
- **内容**：源码、数据库、服务器配置、微信后台配置
- **验收**：有备份文件；能回滚；Git 分支干净
- **回滚**：无（这是第一步）

### N01 - 审计 ✅

- **目标**：审计原项目，明确复用和改造范围
- **输出**：审计报告（已完成）
- **验收**：明确哪些能复用、哪些必须改
- **结论**：可以继续开发

### N02 - PRD 冻结 ✅

- **目标**：冻结顾客端 PRD、页面范围、业务边界
- **输出**：PRD 文档、范围边界文档
- **验收**：客户确认边界
- **关键决策**：
  - 顾客身份：微信 openid + 手机号
  - 员工身份：账号密码 + 角色
  - 默认进入顾客端，店长入口在"我的"
  - 游客可浏览，预约时才授权

### N03 - 数据/权限设计 ✅

- **目标**：设计数据模型、权限模型、状态机
- **输出**：数据模型文档、权限矩阵、业务流程文档
- **验收**：明确顾客表、预约表、门店经纬度字段、角色权限
- **实现状态**：后端数据层已实现（customer_types.go, customer_store.go）

### N04 - 接口文档 ✅

- **目标**：输出接口文档
- **输出**：接口文档草案
- **验收**：全部接口有入参、出参、权限说明

### N05 - 页面流程验收用例 ✅

- **目标**：页面流程和验收用例
- **输出**：页面规格文档、验收用例文档
- **验收**：每个页面有入口、字段、按钮、异常状态、验收标准

### N06 - 后端开发 ✅

- **目标**：实现顾客登录、手机号授权、门店、商品、预约接口

  - StoreInfo 经纬度字段 ✅
  - 微信登录流程 ✅
  - HTTP handler 函数 ✅
  - 路由注册 ✅
  - 顾客 token 中间件 ✅

- **回滚**：删除新增 handler 和路由，不影响现有功能

### N07 - 顾客端开发 ✅

- **目标**：小程序顾客端页面开发
- **依赖**：N06 后端接口
- **项目组织**：miniapp-customer/ 独立小程序（与 miniapp/ 员工端分离），主包含 4 TabBar 页 + pkg-customer/ 分包含子页面
- **TabBar 方案**：原生 TabBar（4 Tab：首页/款式/门店/我的，金色 #866E23 选中色）
- **子阶段划分**：
  1. ✅ 子阶段 1：项目骨架 + 公共层（5 个 utils）+ TabBar 图标 + 首页（Tab 1）+ 其他 3 Tab 占位
  2. ✅ 子阶段 2：款式 Tab（列表+详情）+ 门店 Tab（列表+详情）
  3. ✅ 子阶段 3：预约模块（创建+列表+详情+修改备注）+ 我的 Tab（用户卡+快捷入口+服务卡片+店长入口）
- **交付**：11 个页面（4 主包 + 7 分包），全部 44 文件（4 件套齐全），JS/JSON 语法校验通过
- **验收**：打开默认顾客端；可看商品、门店、提交预约、查看我的预约
- **回滚**：删除 miniapp-customer/ 整个项目，不影响 miniapp/ 员工端

### N08 - 员工端改造 ✅

- **目标**：员工从"我的-店长入口"登录
- **依赖**：N06 后端接口
- **内容**：
  1. 新增预约列表页（pages/appointments/index）— 8 状态筛选 + 卡片列表 + 下拉刷新
  2. 新增预约详情页（pages/appointment-detail/index）— 状态操作按钮 + 顾客信息 + 拨打电话
  3. 首页添加"预约管理"快捷入口 + 待确认预约数提示条
  4. 预约 API 封装（utils/appointmentStore.js）
  5. 顾客端店长入口对接（wx.navigateToMiniProgram 跳转员工端）
  6. 权限配置（appointments.view 添加到 boss/shop_manager 角色）
- **状态操作矩阵**：
  - PENDING → 确认(CONFIRMED) / 拒绝(TERMINATED)
  - CONFIRMED → 到店(ARRIVED) / 终止(TERMINATED)
  - ARRIVED → 完成(COMPLETED) / 未到(NO_SHOW)
- **验收**：员工从"我的-店长入口"登录；可查看预约列表、筛选状态、更新预约状态
- **回滚**：恢复原登录入口，删除新增页面和配置
