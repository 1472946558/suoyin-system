## 3. 代码级根因修复

### 3.1 后端预约写入一致性

新增统一 `persistCustomerAppointmentLocked` 出口。创建、取消、顾客备注、员工状态、后台取消和后台备注在持久化失败时都恢复内存旧值，并向客户端返回 50302。这样不会出现接口返回成功但 MySQL 未写入的假成功。

### 3.2 后端生产配置 fail-fast

`persistent` 模式现在拒绝以下不安全启动条件：默认 token secret、wildcard/空 CORS、mock login、缺少微信 AppID/Secret。持久化 Compose 模板已将 `TOKEN_SECRET` 和 `CORS_ORIGIN` 改为必填变量。本地 memory 模式不受影响。

### 3.3 前端数据状态明确化

门店页、门店详情、首页导航统一只接受有效非零数字坐标；没有坐标时展示禁用态和明确原因，不用错误地图调用掩盖后台数据问题。顾客首页轮播保留服务端 Banner 优先、fallback 兜底。
