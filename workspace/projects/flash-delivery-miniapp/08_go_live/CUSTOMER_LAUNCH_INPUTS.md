# 疾蜂同城急送小程序 客户上线要素收口表

## 使用说明

这份文档用于在进入真实后端和商用能力开发前，先把客户必须提供的上线资料一次性收齐。

- 当前项目状态：前端 MVP 已交付，可 Demo，不可直接商用上线。
- 当前缺口：正式域名、HTTPS 正式 API 域名、微信小程序 AppID 未提供；真实后端、地图、支付、客服未接。
- 建议做法：先由客户和我方一起补齐下面 P0 项，再决定是否进入后端和商用能力阶段。

## 我方进入下一阶段的门槛

- P0 项全部拿到，才进入正式 AppID 导入、域名白名单配置、生产模式切换。
- API 测试域名和后端负责人确认后，才进入真实后端联调。
- 地图 Key、支付商户号、客服入口确认后，才进入商用能力开发。

## 填完后的执行顺序

1. 客户补齐本表 P0 项。
2. 我方把 `utils/config.js` 从占位信息切到客户真实配置。
3. 客户在微信公众平台配置合法域名并开放开发/体验权限。
4. 我方联调真实订单接口。
5. 再决定是否继续进入地图、支付、客服和审核提交流程。
