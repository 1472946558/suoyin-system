# 项目卡：疾蜂同城急送小程序

## 项目定位

原创同城即时配送微信小程序。业务模式参考“同城急送 / 专人直送 / 即时配送”的通用业务链路，但不复制“闪送”的商标、品牌素材、文案、页面结构和专有交互。

当前主交付模式：

- 模板源码交付
- 可演示
- 可二次开发
- 不默认包含当前项目直接上线

## 今日交付目标

在 2026-05-09 当天交付一个原生微信小程序 MVP：

- 首页可展示服务卖点、价格预估、常用场景。
- 用户可填写寄件地址、收件地址、物品类型、重量、备注。
- 可生成模拟订单。
- 可查看订单状态和骑手轨迹式进度。
- 可查看历史订单。
- 可进入个人中心查看常用地址、优惠券、客服入口。

## 技术栈

- 微信小程序原生开发。
- WXML / WXSS / JavaScript。
- 本地 mock 数据。
- 后续可接 Go / Java / Node 后端 REST API。

## 当前交付边界

当前可完成：可演示、可体验、可二次开发的模板源码前端 MVP。

当前不默认承诺直接上线，原因：

- 未接真实定位和地图路线。
- 未接支付。
- 未接真实订单后端。
- 未接骑手调度系统。
- 未配置隐私协议、用户协议、平台备案。
- 未接消息通知、短信、客服、发票。

但以上项不影响“模板源码交付”成立。

## 商用安全原则

- 使用原创品牌：疾蜂同城急送。
- 不使用“闪送”商标。
- 不复制闪送 UI 截图、图标、文案、素材。
- 只参考同城配送通用业务流程。
