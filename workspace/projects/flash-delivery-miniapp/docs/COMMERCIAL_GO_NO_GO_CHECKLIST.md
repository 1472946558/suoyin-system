只看这 7 项。

全过，才可以对客户说：`可商用交付`。

少 1 项，都只能说：`可演示 / 可联调 / 可定制`。

## 7 项检查

| 项目 | 必须达到 | 结果 |
| --- | --- | --- |
| 1. 真实后端 | 不再用 mock，真实接口可用 | [ ] |
| 2. 主链路 | 登录、下单、订单、跟踪全跑通 | [ ] |
| 3. 支付退款 | 至少 1 套真实可验证流程 | [ ] |
| 4. 合规资料 | 隐私协议、用户协议、客服入口可访问 | [ ] |
| 5. 正式配置 | 正式 AppID、正式域名、HTTPS 已配好 | [ ] |
| 6. 真机验收 | 真机完整跑通，异常情况也测过 | [ ] |
| 7. 留痕证据 | 有部署说明、配置清单、验收记录 | [ ] |

## Go / No-Go 规则

- 7 项全过：`Go`，可以说“可商用交付”
- 任意 1 项没过：`No-Go`，不能说“可商用交付”

## 当前项目结论

- 当前状态：`模板源码可交付`
- 当前不是：`可商用交付`
