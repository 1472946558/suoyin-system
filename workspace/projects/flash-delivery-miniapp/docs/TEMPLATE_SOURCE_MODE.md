# 疾蜂同城急送小程序 模板源码模式说明

## 当前定位

这个项目现在的主目标不是“把当前这一份直接部署上线”，而是做成一份可重复卖给多个客户的模板源码。

交付物定义改为：

- 一套可直接导入微信开发者工具的原生小程序源码
- 一套可替换品牌、配色、文案、电话、协议地址的模板结构
- 一套 mock 可演示流程，方便客户先看效果
- 一套可选的后端接入预留层，但不默认承诺本轮联调和上线

## 适合怎么卖

适合交付给这几类客户：

- 想先买现成同城配送小程序模板，再自己改品牌和文案
- 想先拿源码做演示、招商、找团队继续开发
- 暂时不需要你包上线，只需要一份可复用前端模板

不适合默认承诺：

- 直接上线运营
- 真实支付收款
- 真实骑手调度
- 真实地图路线和客服闭环

## 模板源码交付范围

当前这份模板源码默认包含：

- 首页
- 下单页
- 订单列表
- 订单详情
- 配送跟踪
- 我的页面
- 登录/注册资料页
- mock 数据和本地存储
- 全局主题变量
- REST API 预留配置

## 客户拿到源码后通常改什么

客户或后续开发通常只需要先改这些：

- 小程序名称
- 品牌色
- 首页文案
- 联系电话
- 协议地址
- 默认业务城市
- 图片和图标素材
- 下单字段和价格说明

如果客户后面真要上线，再进入第二阶段：

- 接真实后端
- 配正式 AppID
- 配合法域名
- 接地图
- 接支付
- 接客服

## 推荐交付模式

建议按两阶段卖：

### 阶段一：模板源码交付

交付内容：

- 可运行源码
- mock 演示闭环
- 可改品牌的模板结构
- 主要页面和组件说明

验收标准：

- 微信开发者工具可导入
- `npm run validate` 通过
- mock 下单主链路可演示
- 品牌词、配色、文案可替换

### 阶段二：定制开发或上线联调

可作为单独收费项：

- 接客户后端
- 改业务字段
- 接支付
- 接地图
- 接客服
- 提审和上线支持

如果要把“上线联调”进一步做成“可商用交付”，请按：

`docs/COMMERCIAL_DELIVERY_STANDARD.md`

里的 Level 3 标准验收，不要只凭 Demo 或接口联通就对客户承诺商用可用。

如果只需要最短执行版，请直接看：

`docs/COMMERCIAL_GO_NO_GO_CHECKLIST.md`

如果只需要客户拿到后马上能改、能交、能卖，请直接看：

- `docs/TEMPLATE_PRODUCT_INDEX.md`
- `docs/TEMPLATE_QUICK_EDIT_CHECKLIST.md`
- `docs/CUSTOMER_HANDOFF_PACKAGE.md`
- `docs/TEMPLATE_DELIVERY_PACKAGES.md`

## 你内部执行时的判断标准

- 只要模板源码可导入、可演示、可改造，就可以进入“模板可交付”状态。
- 不要再把“缺 AppID、缺域名、缺备案”当作当前阶段阻塞。
- 这些不是模板源码阶段的阻塞，而是未来“上线联调阶段”的阻塞。

## 当前结论

这项目现在应定义为：

`同城配送微信小程序模板源码（可演示、可复用、可二次开发）`

而不是：

`等待当前客户补资料后上线的单项目交付`
