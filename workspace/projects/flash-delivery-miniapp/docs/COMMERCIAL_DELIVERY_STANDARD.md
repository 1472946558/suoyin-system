# 疾蜂同城急送小程序 商用交付标准

## 这份标准解决什么问题

模板源码可以卖，但不能把“源码可交付”和“项目可商用”混为一谈。

以后对客户要分 3 个等级说清楚：

1. 模板源码可交付
2. 定制版本可联调
3. 商用版本可上线

只有达到第 3 级，才可以对客户说：

`这份交付已经具备商用能力，可以进入正式运营或正式提审。`

## 一句话判断标准

判断是不是“可商用交付”，不要看页面是不是好看，也不要看 Demo 能不能跑。

只看 5 类东西有没有闭环：

- 真实业务链路
- 真实技术环境
- 真实合规资料
- 真实运营闭环
- 真实验收证据

5 类里只要有一类没闭环，就不能说“已经可商用交付”。

## 三层交付等级

### Level 1: 模板源码可交付

适用场景：

- 卖模板
- 卖前端源码
- 给客户做演示和二开基础

要求：

- 微信开发者工具可导入
- `npm run validate` 通过
- mock 主链路能演示
- 品牌、配色、文案、电话、协议地址可替换

不能宣称：

- 不能宣称可直接运营
- 不能宣称真实收单
- 不能宣称支付可用

### Level 2: 定制版本可联调

适用场景：

- 客户已经决定继续做
- 开始接真实后端和真实配置

要求：

- 正式或测试 AppID 已提供
- 合法域名已配置
- `mode=production`
- 后端测试环境可访问
- 登录、下单、订单、跟踪能打到真实接口
- 错误提示和异常提示可见

不能宣称：

- 不能宣称已上线
- 不能宣称已具备正式运营能力

### Level 3: 商用版本可上线

适用场景：

- 客户要正式提审
- 客户要收真实订单
- 客户要进入正式运营

必须同时满足下面 5 类标准。

## 5 类商用闭环标准

### A. 真实业务链路闭环

必须跑通：

- 用户登录
- 手机号或身份获取
- 下单
- 价格计算
- 订单列表
- 订单详情
- 配送跟踪
- 支付
- 退款/取消
- 客服或异常处理入口

验收要求：

- 不能再使用 mock 冒充真实结果
- 同一笔订单能在列表、详情、跟踪中一致显示
- 支付成功后的订单状态正确更新
- 取消、退款、失败单有明确状态和提示

### B. 真实技术环境闭环

必须具备：

- 正式 AppID
- 正式 API 域名
- HTTPS
- 微信/平台合法域名配置
- 可用的生产后端
- 数据库和必要缓存
- 监控或日志定位能力
- 基础回滚方案

验收要求：

- 真机测试可访问正式环境
- 接口超时、失败、空数据时有明确处理
- 生产配置与测试配置可区分
- 至少能定位订单失败、支付失败、接口失败

### C. 真实合规资料闭环

必须具备：

- 隐私政策
- 用户协议
- 品牌原创或合法授权证明
- 平台要求的备案/资质
- 敏感信息采集说明

验收要求：

- 页面内能打开隐私政策和用户协议
- 不使用未授权品牌、截图、图标、素材
- 地址、手机号、定位等敏感数据有对应说明

### D. 真实运营闭环

必须具备：

- 客服入口
- 售后/退款规则
- 异常订单处理人
- 配送或履约责任边界
- 运营时段和服务范围

验收要求：

- 用户遇到问题时有真实联系人或系统入口
- 退款、投诉、异常单不是“后面再说”
- 非服务时段、超范围地址、下单失败有明确规则

### E. 真实验收证据闭环

必须留下：

- 测试账号或测试方式
- 真机测试记录
- 主链路验收记录
- 异常链路验收记录
- 部署记录
- 配置清单

验收要求：

- 不是口头说“跑通了”
- 必须有文档、截图、日志、命令或录屏证据
- 能回溯这次交付到底跑通了什么

## 最小商用验收门槛

如果你想把模板做成“可以交付给客户直接商用”的版本，最低要做到：

1. 前端不再依赖 mock
2. 后端真实下单链路跑通
3. 支付和退款至少有一套真实可验证流程
4. 隐私协议、用户协议、客服入口可访问
5. 真机完整跑通主链路
6. 有部署与回滚说明
7. 有验收证据

少任意一项，都只能叫：

- 可演示
- 可联调
- 可定制

不能叫：

- 可商用交付

## 你以后怎么卖最稳

最稳的卖法不是一句“这套源码可以商用”，而是拆成 3 个包：

### 包 1：模板源码包

卖点：

- 交付快
- 成本低
- 适合演示和招商

### 包 2：定制联调包

卖点：

- 接客户品牌
- 接客户后端
- 改业务字段和流程

### 包 3：商用上线包

卖点：

- 负责上线前闭环
- 负责提审准备
- 负责主链路真机验收

这样你不会把“模板钱”卖成“上线钱”，也不会把“联调钱”白送成“售后钱”。

## 对客户的标准说法

你可以直接这样说：

> 这套源码本身可以交付，也适合商用改造；但只有在真实后端、真实支付、真实合规资料、真实客服闭环和真机验收都跑通后，我才会把它定义为“可商用交付版本”。如果只是交付模板源码，那是模板级交付，不等于已经具备正式运营能力。

## 当前项目对应结论

当前这个项目已经达到：

- `Level 1 模板源码可交付`

如果要做到：

- `Level 3 商用版本可上线`

还需要进入第二阶段，把 5 类闭环补齐。
