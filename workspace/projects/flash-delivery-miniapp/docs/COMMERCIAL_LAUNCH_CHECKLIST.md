# 商用上线清单

## 当前结论

今天可以交付原生小程序前端 MVP，但不能直接声明“完整商用上线”。正式上线还需要以下能力。

## 必须补齐

| 模块 | 必须项 | 说明 |
| --- | --- | --- |
| 账号 | 手机号授权、用户协议 | 微信平台合规要求 |
| 隐私 | 隐私政策、个人信息处理说明 | 地址、电话、定位都是敏感信息 |
| 定位 | 腾讯位置服务或微信地图 | 取件/收件地址解析 |
| 支付 | 微信支付商户号 | 运费支付、退款 |
| 后端 | 订单、用户、地址、支付、骑手状态 | 前端不能独立商用 |
| 骑手 | 骑手端或调度后台 | 接单、取件、送达 |
| 消息 | 订阅消息、短信或客服通知 | 状态通知 |
| 客服 | 投诉、退款、异常处理 | 商用运营必备 |
| 安全 | 风控、限流、防刷单 | 防止恶意下单 |
| 合规 | 品牌原创、素材授权、服务资质 | 不能使用“闪送”商标和素材 |

## 上线前门禁

1. 不出现“闪送”名称、logo、截图、版权素材。
2. 小程序隐私协议通过微信平台审核。
3. 后端接口压测和异常测试通过。
4. 支付和退款流程通过沙箱/正式测试。
5. 订单状态全链路可追踪。
6. 客服和投诉入口可用。
7. QA 主路径和异常路径通过。

## 建议上线阶段

| 阶段 | 目标 |
| --- | --- |
| D0 | 前端 MVP 和业务演示 |
| D1-D3 | 接入后端订单和地图定位 |
| D4-D5 | 接入支付、订阅消息、客服 |
| D6-D7 | QA、合规、微信审核 |

## 风险

- 同城配送涉及真实地址和手机号，隐私合规要求高。
- 支付、退款、投诉是商用核心，不能用 mock 代替。
- 骑手调度是业务成败关键，需要后端和运营配合。
