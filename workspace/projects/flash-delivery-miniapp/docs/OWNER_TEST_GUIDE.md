# 老板自测与演示指南

## 目标

这份文档用于你先把资料配置进小程序，完整跑通登录、下单、订单详情、配送跟踪、我的页面，再决定是否交给客户接入服务器。

## 正常模式说明

当前 `project.config.json` 使用 `touristappid`，所以微信开发者工具会在控制台输出游客模式相关警告，例如 `wx.operateWXData` 受限、`webapi_getwxaasyncsecinfo:fail`。这些是微信开发者工具的游客模式限制，不是小程序业务代码错误，也不会展示给真实用户。

要进入正式正常模式，需要：

1. 准备客户自己的微信小程序 AppID。
2. 在微信开发者工具中使用该 AppID 重新导入项目。
3. 在微信公众平台把你加入开发者或体验成员。
4. 在微信公众平台配置 request 合法域名。
5. 将 `utils/config.js` 的 `mode` 从 `mock` 改为 `production`。
6. 填入客户服务器 `apiBaseUrl`、客服电话、隐私协议、用户协议。

## 你现在怎么自测

1. 打开微信开发者工具，导入 `/Users/xiaoliao/Desktop/openclaw/workspace/projects/flash-delivery-miniapp`。
2. 点击底部“我的”。
3. 点击“登录 / 注册”或“去登录/注册”。
4. 点击“一键填测试资料”，也可以手动改成你的姓名、电话、微信、QQ、默认取件地址、默认收件地址。
5. 点击“保存并登录”。
6. 回到“我的”，确认姓名、电话、微信、QQ 和默认地址显示正确。
7. 点击底部“下单”，确认默认地址已自动带入。
8. 修改物品类型、重量、备注，点击“提交订单”。
9. 进入订单详情后，点击“查看配送跟踪”。
10. 点击底部“订单”，确认新订单出现在订单列表。

## 演示视频脚本

1. 开场：展示首页，说明这是原创同城急送小程序前端，不使用竞品商标和素材。
2. 登录：进入“我的”，点击“登录 / 注册”，一键填测试资料并保存。
3. 下单：进入“下单”，展示默认地址、物品类型、重量、价格预估。
4. 创建订单：点击“提交订单”，进入订单详情。
5. 跟踪：进入“跟踪”，展示订单状态流。
6. 订单列表：进入“订单”，展示历史订单和新订单。
7. 客户接入说明：打开 `docs/CUSTOMER_INTEGRATION_GUIDE.md`，说明客户只需替换 AppID、域名和 API。

## 当前商用边界

当前版本可以作为“可演示、可二次开发、可接后端”的前端交付包。真正上线还需要客户补齐后端订单、微信登录、手机号授权、地图定位、支付、骑手调度、隐私协议、客服投诉和运营资质。
