# PRD：疾蜂同城急送小程序

## 用户角色

| 角色 | 目标 |
| --- | --- |
| 普通用户 | 快速创建同城配送订单，查看价格和配送进度 |
| 商家用户 | 高频下单，管理历史订单 |
| 客服/运营 | 后续处理异常订单、投诉、退款 |
| 骑手 | 后续接单、取件、送达 |

## 核心业务链路

```text
打开小程序
  -> 选择寄件地址
  -> 选择收件地址
  -> 填写物品信息
  -> 获取价格预估
  -> 提交订单
  -> 查看骑手接单/取件/配送/送达状态
  -> 查看历史订单
```

## 页面清单

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 首页 | `pages/home/index` | 品牌、快捷下单、价格预估、服务场景 |
| 下单 | `pages/order/index` | 寄/收地址、物品、重量、备注、下单 |
| 跟踪 | `pages/track/index` | 当前订单状态、进度、骑手信息 |
| 订单 | `pages/orders/index` | 历史订单列表 |
| 我的 | `pages/profile/index` | 用户信息、常用地址、优惠券、客服 |
| 订单详情 | `pages/order-detail/index` | 单个订单详情 |

## 订单字段

| 字段 | 说明 |
| --- | --- |
| `id` | 订单号 |
| `fromAddress` | 寄件地址 |
| `toAddress` | 收件地址 |
| `itemType` | 物品类型 |
| `weight` | 重量 |
| `note` | 备注 |
| `price` | 预估价格 |
| `distance` | 模拟距离 |
| `status` | 订单状态 |
| `createdAt` | 创建时间 |

## 订单状态

```text
created -> accepted -> picked -> delivering -> completed
```
