# 图标系统说明

## 当前选择

图标来源：Lucide。

授权：ISC License，可用于商业项目，但交付时需保留第三方授权说明。

生成方式：

```bash
npm install
npm run icons
```

## 使用原则

- 不使用来源不明的在线素材。
- 不直接复刻竞品图标。
- 所有页面图标统一线宽、圆角、留白和品牌色点缀。
- tabBar 使用透明线性图标，页面功能入口使用带轻阴影的圆角图标底板。
- 需要新增图标时，只改 `scripts/generate-brand-icons.mjs` 的映射表，再运行 `npm run icons`。

## 已生成资产

- `assets/ui/*.png`：页面功能图标。
- `assets/tabbar/*.png`：底部导航图标。

## UI 验收标准

- 图标风格一致，不混用卡通、写实、emoji、临时文字图标。
- 小图标在 iPhone 12/13 预览下仍可识别。
- 深色卡片里的图标必须有足够对比度。
- 所有图标必须服务业务含义，不能只为装饰。
- 如果图标看起来廉价，UI/UX Agent 必须打回前端，不允许进入交付结论。
