# 模板产品交付包说明

这份说明只做一件事：把 `模板源码包 / 定制联调包 / 商用上线包` 说清楚，避免客户把“拿到源码”理解成“默认能直接开业”。

建议对外就按这 3 档卖，不混说，不打包票。

## 1. 模板源码包

### 适合谁

- 想先拿一套现成小程序去演示、招商、内部评估的人
- 有自己技术团队，准备后续自己二开的人
- 预算先控住，先买底座，再决定要不要继续做联调和上线的人

### 交付内容

- 一套可导入微信开发者工具的原生小程序源码
- 已有页面骨架：首页、下单、订单列表、订单详情、配送跟踪、我的
- mock 演示链路，可用于看页面、走流程、录 Demo
- 可替换的品牌位：名称、主色、文案、客服电话、协议链接
- 已整理的项目文档：接入说明、QA 清单、商用边界说明

### 客户需提供什么

- 品牌名称、Logo、主色、基础文案
- 联系电话、客服方式
- 隐私政策和用户协议链接
- 如果后续要继续做，提前确认是否有自己的后端、域名、AppID

### 不能默认承诺什么

- 不能默认承诺“拿到就能直接上线运营”
- 不能默认承诺“已经接好客户自己的服务器”
- 不能默认承诺“支付、退款、地图、短信、消息通知都能直接用”
- 不能默认承诺“通过微信审核”
- 不能默认承诺“适配客户现有业务规则、价格规则、城市范围、履约流程”

## 2. 定制联调包

### 适合谁

- 已经决定继续做，不只看 Demo，要开始接真实业务的人
- 已有后端团队或现成接口，需要前端配合联调的人
- 要改品牌、字段、业务流程、接口映射的人

### 交付内容

- 在模板基础上替换成客户品牌版本
- 接入客户测试环境或预发布环境
- 按已确认接口做前端联调：登录、下单、订单、跟踪等主流程
- 按约定范围调整页面字段、按钮文案、表单项、状态展示
- 提供联调问题清单和联调验收记录

### 客户需提供什么

- 小程序 AppID
- HTTPS 接口域名和接口文档
- 测试环境账号、鉴权方式、联调联系人
- 字段映射、订单状态流转、价格规则、异常提示规则
- 客服入口、协议地址、地图 Key、支付参数等已明确的业务资料

### 不能默认承诺什么

- 不能默认承诺“联调完就等于可以商用上线”
- 不能默认承诺“客户后端问题由我们兜底解决”
- 不能默认承诺“所有未写进范围的页面、接口、活动功能、管理后台一起做完”
- 不能默认承诺“支付、退款、发票、骑手调度、风控、消息通知天然包含”
- 不能默认承诺“上线审核材料、资质、合规文件由我们代办”

## 3. 商用上线包

### 适合谁

- 要正式提审、正式接单、正式运营的人
- 不接受“只能演示”或“只能联调”，要交付到可上线状态的人
- 需要把技术、配置、合规、验收一起闭环的人

### 交付内容

- 基于客户正式环境完成最终版本配置
- 主业务链路验收通过：登录、下单、订单列表、订单详情、配送跟踪
- 生产域名、正式 AppID、正式接口配置完成
- 上线前检查资料：协议链接、客服入口、基础配置项、验收记录
- 提供上线前交付清单、测试结论、已知风险说明

### 客户需提供什么

- 正式 AppID、正式域名、正式 HTTPS 服务
- 生产可用后端及可配合排障的接口负责人
- 微信审核所需资料、隐私政策、用户协议、主体资质
- 客服方式、售后规则、退款规则、服务范围、营业时间
- 支付商户、地图服务、消息通知等正式商用能力

### 不能默认承诺什么

- 不能默认承诺“平台百分百审核通过”
- 不能默认承诺“上线后没有任何运营故障或接口波动”
- 不能默认承诺“客户未提供的资质、支付、地图、客服、履约能力可由模板自动补齐”
- 不能默认承诺“未做的后台系统、运营系统、财务系统、骑手系统自动包含”
- 不能默认承诺“上线后长期代运营、长期客服、长期运维监控都默认包含”

## 建议销售话术

- 要得快、预算低：卖 `模板源码包`
- 要接自己系统、做成自己品牌：卖 `定制联调包`
- 要正式开业、正式提审、正式接单：卖 `商用上线包`

一句话讲清楚：

`源码包解决“你先有一套可展示的产品”，联调包解决“这套产品开始接你的真实业务”，上线包解决“这套产品可以进入正式商用准备”。`
