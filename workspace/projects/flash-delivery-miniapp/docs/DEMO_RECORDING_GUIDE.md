# 演示视频录制指南

## 录制路线

1. 打开微信开发者工具，确认项目路径为 `flash-delivery-miniapp`。
2. 从首页开始录制，展示品牌、常用急送、价格预估和服务保障。
3. 点击底部“我的”，展示已登录资料；如果未登录，点击“编辑资料”或“去登录/注册”。
4. 在登录/注册页点击“一键填测试资料”，再点击“保存并登录”。
5. 点击底部“下单”，展示默认地址自动带入、物品类型、重量、备注和预估费用。
6. 点击“提交订单”，展示订单详情。
7. 点击“查看跟踪”，展示配送状态和模拟路线。
8. 点击底部“订单”，展示订单列表和最新订单。
9. 结束时打开 `docs/CUSTOMER_INTEGRATION_GUIDE.md`，说明客户只要替换 AppID、服务器域名和 RESTful API 即可接入。

## 录屏权限

如果需要我在本机直接录制，macOS 需要给当前运行环境屏幕录制权限：

1. 打开“系统设置”。
2. 进入“隐私与安全性”。
3. 打开“屏幕录制与系统音频录制”。
4. 给 Codex、终端或当前执行录屏命令的应用授权。
5. 重新启动对应应用后再录制。

## 推荐交付口径

当前演示视频应说明：这是原创同城急送小程序前端交付包，已完成登录资料、下单、订单详情、订单列表、配送跟踪和 RESTful API 接入层。正式上线仍需要客户接入真实后端、微信小程序 AppID、合法域名、地图、支付、客服和隐私合规。
