## Severity Levels

| Level | Meaning | Response Time |
|-------|---------|---------------|
| CRITICAL | System down / data loss | Immediate |
| HIGH | Feature broken / wrong output | < 1 hour |
| MEDIUM | Degraded performance / workaround exists | Same day |
| LOW | Cosmetic / minor inconvenience | Next cycle |

## Logging Rules

1. Every error gets an ID — no anonymous entries
2. Root cause must be filled in, even if preliminary
3. If the same error appears 3 times, it escalates to LESSONS_LEARNED.md
4. Prevention rule must be actionable, not vague
5. Status: OPEN → FIXED → VERIFIED → CLOSED
