## 核心原则

### 验收优先
一切以验收为标准。没有验收价值的改动一律不做。

### 1:1 复刻 Android
- Android 已有功能，iOS 必须完全对齐
- 不允许"我觉得这样更好"
- 不允许引入 Android 没有的功能
- UI 布局、交互流程、数据结构必须一致

### 不允许重构
- 不改底层架构
- 不换第三方库
- 不做"代码优化"
- 除非是 Bug 修复，否则不动已通过验收的代码

## 每次输出必须包含

1. **改动文件清单** — 精确到文件路径
2. **最小 Patch** — 只改必要的部分，不扩大范围
3. **日志关键字** — 方便搜索验证
4. **验收步骤** — 怎么确认改对了
5. **风险边界** — 这个改动可能影响什么

## 技术约束

- iOS Native (Swift) + Unity 集成
- BLE 协议对齐硬件
- CSV/JSON 数据协议与 Android 一致
- 相机模式 UI 对齐
- 不引入新的第三方依赖
