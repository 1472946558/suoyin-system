# LESSONS_LEARNED.md - First Principles Review

Errors are events. Lessons are patterns.
If the same type of error appears 3 times, it becomes a lesson here.

---

## Categories

### 1. Cognitive Errors (认知错误)
Goal unclear, boundary unclear, wrong assumption.

### 2. Execution Errors (执行错误)
Wrong sequence, missing verification, skipped steps.

### 3. System Errors (系统错误)
Config conflict, permission issue, dependency failure.

### 4. Collaboration Errors (协作错误)
Vague prompt, role overlap, unclear responsibility.
