# Skill: Amazon Listing Review

## Purpose
Amazon.de Listing 质量检查框架。

## 检查清单

### 标题（Title）
- [ ] 核心关键词在前 60 字符
- [ ] 包含品牌名
- [ ] 包含主要特征（颜色/尺寸/数量）
- [ ] 长度 150-200 字符
- [ ] 无促销词汇（Best, Free 等）

### 五点描述（Bullet Points）
- [ ] 每条 200-500 字符
- [ ] 第一条放最核心卖点
- [ ] 包含关键词但自然
- [ ] 有具体数据（尺寸/材质/数量）
- [ ] 德语语法正确

### 图片（Images）
- [ ] 主图白底，1000x1000 以上
- [ ] 至少 5 张图
- [ ] 包含使用场景图
- [ ] 包含尺寸对比图
- [ ] 包含细节图

### A+ 内容
- [ ] 品牌故事模块
- [ ] 产品特性模块
- [ ] 对比模块
- [ ] 图片质量高

### 后台关键词
- [ ] 填满 250 字节
- [ ] 不重复标题已有词
- [ ] 包含德语近义词
- [ ] 无竞品品牌名

## 评分

| 维度 | 满分 | 及格 |
|------|------|------|
| 标题 | 25 | 18 |
| 五点 | 25 | 18 |
| 图片 | 25 | 18 |
| A+ / 后台 | 25 | 18 |
| **总分** | **100** | **72** |
