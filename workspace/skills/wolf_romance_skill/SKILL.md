# SKILL.md - Werewolf Novel Publishing

## Skill Name

Werewolf Novel Publishing

## 概述

海外狼人文（Paranormal Romance）商业小说的全链路生产与运营能力。覆盖从市场调研、选题、写作、封面、上架到广告投放的完整流程。

## 核心能力

### 1. 海外狼人文市场调研
- Amazon Kindle 狼人文榜单分析
- GoodNovel 热门狼人文追踪
- Facebook 广告素材收集
- 爆款关键词与标题记录
- 竞品系列结构与定价分析

### 2. 英文狼人文写作
- 题材：Rejected Mate / Alpha / Secret Baby / Second Chance / Forced Marriage / Enemies to Lovers / Possessive Alpha
- 结构：三幕式 / Save the Cat / Romance Beat Sheet
- 风格：美式英文、情绪驱动、短句强动词、第一/第三人称灵活切换
- 标准流程：伤害 → 成长 → 反击 → 后悔 → HEA

### 3. 翻译与本地化
- 将中文创意重写为地道英文商业小说
- 非直译，而是文化适配
- 情绪表达本地化

### 4. 系列规划
- 每月 1 个系列，4 本书
- 每本 25,000–35,000 words
- 每本独立可卖 + 为下一本导流
- Cliffhanger 结尾设计

### 5. Amazon KDP 上架
- Kindle 类目选择
- 关键词优化
- 标题 / 简介撰写
- 定价策略

### 6. GoodNovel 连载
- 连载节奏规划
- 章节断点设计
- 付费墙策略

### 7. Facebook 广告
- 广告文案撰写
- 受众定位
- A/B 测试
- ROI 优化

### 8. AI 封面图
- 封面风格设计（符合美国狼人文审美）
- AI 提示词制作
- 标题排版
- 广告图制作

### 9. 飞书日报
- 每日固定格式日报
- 进度追踪
- 问题上报
- 决策请求

## 输入输出

### 输入
- 一个故事想法 / 中文简介 / 人设
- 市场调研需求
- 广告优化需求
- 封面设计需求

### 输出
- 英文标题（系列名 + 每本标题）
- 系列规划（4 本书结构）
- 章节大纲（每本书）
- 每日写作计划
- 封面提示词（AI 生成用）
- 广告文案（Facebook 用）
- KDP 关键词与分类
- 飞书日报

## SOP: 完整工作流

```
阶段 1: 市场调研
  → 查 Amazon Kindle 狼人文榜单
  → 查 GoodNovel 热门
  → 收集 Facebook 广告素材
  → 记录热门关键词、标题、封面风格

阶段 2: 选题
  → 检验 4 条标准（一句话、强冲突、广告钩子、可系列化）
  → 生成系列名 + 4 本书标题
  → 生成每本书一句话钩子

阶段 3: 写作
  → 第 1 章: 女主被伤害/被拒绝（爆点开场）
  → 第 2 章: Alpha 做错事
  → 第 3 章: 女主决定离开/反击
  → 中段: 男主后悔 + 新冲突
  → 结尾: Cliffhanger + 下一本伏笔

阶段 4: 封面
  → 使用 AI 封面提示词模板
  → 包含: Alpha 男主、月亮、黑森林、强情绪、大标题

阶段 5: KDP 上架
  → 选择类目与关键词
  → 优化标题与简介
  → 定价

阶段 6: 广告投放
  → Facebook 广告文案
  → 受众定位
  → A/B 测试

阶段 7: 数据复盘
  → ROI 分析
  → 点击率分析
  → 下一本优化方向
```

```
now [反转/冲突] after discovering [秘密/真相].
```

## 质量检查清单

每本书完稿前必须通过：

- [ ] 开头 3 句话能抓住读者
- [ ] 每章结尾有钩子
- [ ] 第 1 章有爆点事件
- [ ] 男主有明确的"做错事"和"后悔"弧线
- [ ] 女主有成长弧线
- [ ] Cliffhanger 能驱动读者买下一本
- [ ] 广告标题已测试（至少 3 个版本）
- [ ] 封面符合美国狼人文审美
- [ ] 简介能在 3 句话内讲清楚冲突
- [ ] 字数达标（25,000–35,000 words）
