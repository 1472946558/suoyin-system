# Skill: SOP Generator

## Purpose
从实际操作中生成可复用的 SOP。

## 生成流程

1. 识别重复出现的任务模式
2. 收集实际执行步骤
3. 按模板格式化
4. 添加验证步骤
5. 存储到 workspace/skills/

## SOP 模板

```markdown
# SOP: [标题]

## 元数据
- 创建日期: YYYY-MM-DD
- 最后更新: YYYY-MM-DD
- 适用场景: [什么时候用]
- 预计耗时: [分钟]

## 前置条件
- [条件1]
- [条件2]

## 步骤

### Step 1: [标题]
- 操作: [具体操作]
- 命令: `具体命令`（如有）
- 预期结果: [应该看到什么]

### Step 2: [标题]
...

## 验证
- [ ] [验证项1]
- [ ] [验证项2]

## 故障排除
| 现象 | 原因 | 解决 |
|------|------|------|

## 变更记录
| 日期 | 变更 | 原因 |
|------|------|------|
```

## 触发条件

- 同类任务出现第 3 次
- CEO 要求沉淀
- Agent 完成复杂任务后

## 规则

- SOP 必须来自实际操作，不写理论
- 每个步骤可独立验证
- 保持简洁，一个 SOP 一个主题
- 定期审查过时的 SOP
