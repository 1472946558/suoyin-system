# Skill: Meeting Summary

## Purpose
会议纪要生成模板和流程。

## 纪要结构

```markdown
# 会议纪要 - YYYY-MM-DD

## 基本信息
- 主题: [会议主题]
- 参与人: [列表]
- 时长: [分钟]

## 讨论要点
1. [要点1]
2. [要点2]
3. [要点3]

## 决策
| 编号 | 决策内容 | 负责人 | 截止日期 |
|------|----------|--------|----------|

## 待办事项
- [ ] [待办1] → @[负责人] → [截止日]
- [ ] [待办2] → @[负责人] → [截止日]

## 风险/阻塞
- [风险描述] → [影响] → [需要什么]

## 下次会议
- 时间: YYYY-MM-DD
- 议题: [预设议题]
```

## 规则

- 决策必须有明确结论，不含糊
- 每个待办必须有人和截止日期
- 风险必须标注影响范围
- 纪要当天内发出
- 存档到 workspace/memory/
