# Skill: Amazon Profit Judgement

## Purpose
Amazon.de 利润判断与盈亏分析。

## 成本结构

```
售价（含 VAT）
  - VAT (19%)
  = 净售价
  - 采购成本
  - 头程物流（均摊到单件）
  - FBA 配送费
  - FBA 仓储费（月均摊）
  - 销售佣金（按品类）
  - 广告费（按 ACOS 计算）
  - 退货成本（按退货率计算）
  = 净利润
```

## 利润率等级

| 利润率 | 等级 | 决策 |
|--------|------|------|
| > 30% | 优秀 | 加大投入 |
| 20-30% | 良好 | 正常运营 |
| 15-20% | 一般 | 优化成本 |
| 10-15% | 警告 | 分析原因 |
| < 10% | 危险 | 考虑清仓 |

## 关键公式

```
ACOS = 广告花费 / 广告销售额 × 100%
TACOS = 广告花费 / 总销售额 × 100%
利润率 = (净利润 / 净售价) × 100%
盈亏平衡 ACOS = 利润率（不含广告）
```

## 场景判断

| 场景 | ACOS | 利润率 | 动作 |
|------|------|--------|------|
| 高 ACOS 高利润 | >30% | >25% | 优化广告，不急 |
| 高 ACOS 低利润 | >30% | <15% | 紧急优化或暂停 |
| 低 ACOS 高利润 | <20% | >25% | 最佳状态，放量 |
| 低 ACOS 低利润 | <20% | <15% | 定价或成本问题 |
