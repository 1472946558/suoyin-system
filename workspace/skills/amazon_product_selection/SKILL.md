# Skill: Amazon Product Selection

## Purpose
Amazon.de 德国站选品决策框架。

## 选品评估表

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 利润率 | 30% | >30%=A, 20-30%=B, <20%=C |
| 竞争强度 | 25% | Review<200=A, 200-500=B, >500=C |
| 物流成本 | 15% | 轻小件=A, 中件=B, 大件=C |
| 合规难度 | 15% | 无认证=A, 简单认证=B, 复杂认证=C |
| 退货风险 | 15% | <5%=A, 5-8%=B, >8%=C |

## 利润计算

```
毛利 = 售价 - 采购成本 - 头程物流 - FBA费用 - 佣金
净利润 = 毛利 - 广告费 - 退货成本 - VAT
利润率 = 净利润 / 售价 × 100%
```

## 决策矩阵

| 综合评分 | 决策 |
|----------|------|
| A (≥80分) | 立即上架 |
| B (60-80分) | 深入调研后决定 |
| C (<60分) | 放弃 |

## 德国站特殊注意

- VAT 注册和申报（19%）
- 包装法（LUCID 注册）
- 电子设备需 WEEE 认证
- 食品/化妆品需额外合规
- CE 标志要求
