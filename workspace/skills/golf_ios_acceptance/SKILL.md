# Skill: Golf iOS Acceptance

## Purpose
Golf iOS 项目验收标准与流程。

## 验收流程

1. 确认改动范围（文件列表 vs 合同要求）
2. 确认无新增第三方依赖
3. UI 截图对比 Android
4. 功能流程测试
5. 边界条件测试
6. 日志输出验证

## 必须输出

- 改动文件清单
- 最小 patch 说明
- 日志关键字
- 验收步骤
- 风险边界
- 什么 NOT to change

## 禁止

- 不验收未对齐 Android 的功能
- 不验收引入新依赖的提交
- 不验收重构过的代码
- 不跳过边界条件测试

## Android 对齐规则

| 项目 | 对齐标准 |
|------|----------|
| UI 布局 | 像素级对比（允许 iOS 系统差异） |
| 交互流程 | 步骤完全一致 |
| 数据格式 | JSON/CSV 字段名、类型一致 |
| 错误处理 | 错误码和提示文案对齐 |
| BLE 协议 | 数据包格式完全一致 |
