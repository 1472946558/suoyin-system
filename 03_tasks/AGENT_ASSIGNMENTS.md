# Agent 分工：黄金回收收银小程序

## 项目总控

| Agent | 职责 |
| --- | --- |
| `ai-tech-lead` | 当前项目总技术负责人小龙虾，统一拆任务、控边界、收结果 |

## 需求与方案

| Agent | 职责 |
| --- | --- |
| `ai-pm` | 需求整理、PRD、页面清单、验收标准、待确认问题 |
| `ai-tech-lead` | 技术执行计划、依赖顺序、风险边界 |

## 开发

| Agent | 职责 |
| --- | --- |
| `ai-weapp` | 原生微信小程序页面、组件、交互、前端 mock 主路径 |
| `ai-frontend` | 后台管理端页面、权限配置前端、老板管理后台 |
| `ai-backend` | 账号体系、角色权限、门店模型、订单 / 回收单 / 图片接口 |
| `ai-devops` | 域名、部署、HTTPS、对象存储、支付回调环境 |
| `ai-security` | 支付、权限、敏感数据、审计日志风险把关 |

## 验收

| Agent | 职责 |
| --- | --- |
| `ai-qa` | 主路径验收、角色权限回归、图片上传校验验证 |
